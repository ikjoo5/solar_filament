# 검출 재현율 90%를 향한 후보 선택 실험

사용자 요청에 따라 우선순위를 **FP·FN 감소와 실제 객체 재현율 90%**로 정했다. 이번에는 경계 개선이나 추가 학습 없이, 저장된 예측으로 기존 정답을 유지하면서 누락을 복구하는 규칙 10개를 평가했다. 모두 FN은 감소했지만 FP가 증가하고 PQ가 하락하여 채택하지 않았다.

**목표와 현재 위치**

- 재현율은 최종 출력 마스크와 **IoU > 0.5**로 일치한 고유 GT 수 / 전체 GT 수다. 후보 안에 정답이 존재하는 비율과 구별한다.
- 707장 개발 OOF 기준선: GT 8,199개 중 5,244개 검출, **재현율 63.96%, precision 64.46%, FP 2,891, FN 2,955, PQ 0.436753**.
- 90%를 넘기려면 최소 **7,380개 검출**, FN **819개 이하**가 필요하다. 현재보다 정답 **2,136개**를 추가로 찾아야 한다.
- FN 감소만으로 채택하지 않는다. FP와 precision, RQ, PQ를 함께 확인한다. 이후 경계 개선은 검출·선택의 병목을 줄인 뒤 다시 비교한다.
- 707장 OOF 원시 후보의 정답 존재율은 기본 4개 기하 변환 뷰에서 **86.71%**, 전처리·타일 후보를 포함하면 **92.01%**였다(confidence ≥ 0.05, 면적 ≥ 300). GT로 후보를 하나씩 대조한 진단이며, 중복 제거와 영역 충돌을 처리한 실제 재현율이 아니다. 달성 가능한 성능의 보장이나 확정적인 상한으로 사용하지 않는다.

**평가 범위**

- 고정 분할 실험: 기존 train 616장 / validation 91장. 이번에는 validation의 원시 후보 7,172개와 이미 학습된 epoch 18 품질 점수만 사용했다. 91장에는 평가 주석 그룹 101개, GT 708개가 있다.
- OOF 실험: 707장 / 주석 그룹 1,154개 / GT 8,199개. native는 각 fold 30epoch, YOLO는 fold 순서대로 30/30/30/30/25epoch다. 서로 다른 학습량이라는 제약을 유지해 표기한다.
- 각 실험은 같은 데이터·같은 원시 예측의 기준선과 비교했다. 고정 91장 YOLO 기준선, 707장 OOF 기준선, 과거 제출용 YOLO+native의 검증 PQ 0.472593·public LB 0.39는 서로 직접 비교하지 않는다.
- 규칙을 고정하여 고정 분할 7개 CSV와 OOF 25개 CSV를 생성한 뒤 각각 GT로 평가했다. 두 데이터셋 모두 이전 실험에 반복 사용한 개발 데이터다. 독립 테스트나 리더보드 개선의 증거로 취급하지 않는다.

**고정 91장: 기존 마스크 보존 + YOLO 후보 추가**

기존 마스크를 순서와 내용까지 보존했다. 새 후보는 기존 개별 마스크와 최대 IoU ≤ 0.1, 기존 합집합에 포함되는 비율 ≤ 25%일 때만 추가했다. 새 후보끼리 IoU > 0.5이면 중복 제거하고, 이미 차지한 픽셀을 제외한 뒤 면적 300 이상인지 재확인했다. `c`는 원래 YOLO confidence, `q`는 동결한 품질 점수다.

|규칙|PQ|재현율|Precision|FP|FN|복구 GT / 기존 GT 손실|
|---|---:|---:|---:|---:|---:|---:|
|기준선 c ≥ 0.30|0.430960|63.98%|63.53%|260|255|0 / 0|
|R1: c ≥ 0.10, q ≥ 0.30 추가|0.426506|65.25%|61.27%|292|246|9 / 0|
|R2: c ≥ 0.20, q ≥ 0.30 추가|0.430841|64.69%|63.00%|269|250|5 / 0|
|R3: c ≥ 0.10, q ≥ 0.50 추가|0.430676|64.41%|63.07%|267|252|3 / 0|
|R4: c ≥ 0.20, q ≥ 0.50 추가|0.429305|64.12%|62.97%|267|254|1 / 0|
|R5: c ≥ 0.10만으로 추가|0.397276|71.19%|50.45%|495|204|51 / 0|
|R6: 기존 q ≥ 0.15 최종 결과 중 새 영역 추가|0.411307|67.37%|55.85%|377|231|24 / 0|

- R5는 가장 많은 정답 51개를 복구했지만 FP가 235개 늘었다. 재현율 상승을 성공으로 판정하지 않았다.
- R2는 기준선과 PQ가 가장 가까웠지만, FN 5개 감소에 FP 9개 증가로 개선을 확인하지 못했다.
- 품질 점수로 원래 confidence를 완전히 대체했던 이전 실패와 달리, 이번에는 기존에 맞힌 정답 손실이 전 규칙에서 0개다. 그럼에도 신규 후보의 오검출 비용을 해결하지 못했다.

**707장 OOF: 기존 마스크 보존 + native 후보 추가**

현재 선택한 `C4_then_C2` 결과를 보존했다. native TTA 연결요소가 일반 native 추론과 IoU ≥ 0.5로 일치하고, YOLO 후보의 지원도 받을 때 추가했다. YOLO 지원 조건은 confidence ≥ 0.1, native 후보와 IoU ≥ 0.3이다. 기하 변환·전처리·타일의 서로 다른 계열을 세되, 중복 limb 뷰와 잘린 타일 후보는 제외했다. 기존 영역 보존 및 새 후보 중복 제거 조건은 위 실험과 같다.

|규칙|PQ|재현율|Precision|FP|FN|복구 GT / 기존 GT 손실|
|---|---:|---:|---:|---:|---:|---:|
|기준선 C4_then_C2|0.436753|63.96%|64.46%|2,891|2,955|0 / 0|
|A: native 0.35, 면적 300, 평균 FG 0.7, 지원 1계열|0.426774|66.18%|59.95%|3,624|2,773|182 / 0|
|B: A에서 지원 2계열|0.429657|65.87%|60.98%|3,456|2,798|157 / 0|
|C: B에서 native 0.50|0.429145|65.74%|60.94%|3,454|2,809|146 / 0|
|D: native 0.35, 면적 100, 평균 FG 0.8, 지원 2계열|0.431797|66.11%|61.34%|3,416|2,779|176 / 0|

- A는 FN 182개를 줄였지만 FP가 733개 증가했다. D도 FN 176개 감소에 FP 525개 증가였다.
- 신규 예측만의 precision은 19.89~25.11%였다. 여러 추론 계열에서 반복 등장하거나 native foreground 점수가 높다는 조건만으로 충분히 정확하게 선택하지 못했다.
- 네 규칙 모두 전체 PQ가 낮아졌고, 각 fold에서도 모두 PQ가 하락했다. 기준선은 그대로 유지했다.

**추가 진단: 이번 원본 보존 규칙에서는 기존 FP도 복구를 막는다**

고정 91장에서 GT를 참고하여 실패 원인을 조사했다. 아래 수치는 후보 간 충돌을 무시하고 GT별로 후보가 있는지 조사한 것이며, 실제 제출 가능한 선택기의 성능이 아니다.

|기존 FN 255개에 대한 진단 조건|유효 후보가 남는 GT 수|
|---|---:|
|원시 후보에 IoU > 0.5 후보 존재, c ≥ 0.05|186|
|면적 ≥ 300도 만족|182|
|기존 예측과의 겹침 제한 + 기존 영역 제외 후에도 정답|77|
|GT를 보고 기존 FP만 제거한 뒤 동일 조건 적용|179|

- 좋은 후보가 존재해도 기존 FP가 해당 영역을 차지하면, 새 후보가 겹침 제한에 걸리거나 픽셀이 제거된다.
- 좋은 후보가 모두 겹침 제한에 막힌 GT는 105개였다. 그중 104개에는 현재 FP와 겹치는 후보가 있었고, 5개에는 TP와 겹치는 후보가 있었다. 두 경우에 모두 해당하는 GT 4개가 포함된다. 단순 교집합 존재 분류이므로 이 수치만으로 개별 인과관계를 확정하지 않는다.
- 겹침 제한을 풀고 기존 영역 제외만 적용해도, 전체 원시 후보에서 추가로 일치 가능한 FN은 79개였다. GT를 보고 FP만 제거하면 181개였다. 이 실험의 제약에서는 단순히 겹침 임계값만 푸는 것으로 병목이 해결되지 않았다.
- **77 → 179는 실제 복구 실적이 아니다.** GT를 알아야 가능한 FP 제거와 후보별 독립 확인 결과다. 실제 추론에서는 어떤 기존 예측이 FP인지 판별하고, 충돌하는 후보 중 무엇을 남길지도 결정해야 한다.

**이후 실험 방향과 채택 기준**

- 우선순위: 후보를 더 넣는 규칙만 확대하기보다, **기존 오검출 제거·교체와 정답 후보 선택을 함께 개선**한다.
- 중복 후보를 같은 객체의 대안으로 묶고, 하나의 부정확한 예측이 여러 좋은 후보를 막는 경우를 별도로 비교한다. confidence를 품질 점수로 완전히 대체하는 방식은 이번 결과로 정당화되지 않는다.
- 매 실험마다 기존 GT 유지·손실, 새로 복구한 GT, 추가·제거 FP를 따로 기록한다. 최종 실제 recall을 측정하고, 후보 존재율을 대신 보고하지 않는다.
- 학습이 필요한 선택기 변경은 원래 고정 train/validation에서 수행한다. 5-fold 결과는 전처리·후처리 비교에 사용하며 validation 정답으로 선택기를 학습하지 않는다.
- 현재는 새 규칙 10개 전부 미채택, 재현율 90% 미달이다. 다음 실험 방향이 정해졌으며 성능 개선을 보장하지는 않는다.

**검증 및 재현 자료**

- 기존 CSV 재현, 원본 마스크 보존, 출력 비중첩, 모든 규칙의 기존 GT 손실 0개, 입력·코드 해시를 확인했다.
- PQ는 전체 IoU 합과 TP/FP/FN을 합쳐 계산했다. Fold PQ의 단순 평균을 사용하지 않았다. TP는 공식 평가의 pair 수, recall/precision은 각각 고유 매칭 GT/예측 수를 사용했다. OOF 기준선의 TP pair 5,244개와 고유 매칭 예측 5,243개의 차이를 반영했다.
