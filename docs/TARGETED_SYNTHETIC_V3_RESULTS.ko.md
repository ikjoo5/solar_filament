# 합성 v2 / 어려운 작은 객체 합성 v3 — 30에폭 결과

## 결론

**이번 v3 모델은 기존 YOLO를 대체하지 않는다.** 두 실험 모두 정상적으로 30에폭을 완료했지만, 기존 native를 고정한 최종 파이프라인의 PQ가 낮아졌다. 기존 모델·가중치를 유지하고 추가 에폭을 자동 실행하지 않는다.

두 결과 ZIP은 같은 export `1c6b4bf4ba62`의 전체 2개 part이며, 중복을 제외한 951개 파일의 CRC·SHA256과 목록을 확인했다. 업로드된 Python 코드는 실행하지 않았다. 기존에 검증한 로컬 평가 코드로 최종 CSV 6개를 재계산했고, PQ·FP·FN과 주석 그룹별 결과가 모두 일치했다.

평가 범위는 기존 고정 validation **91장 / 주석 그룹 101개 / GT 708개**다. 같은 사진의 서로 다른 주석자는 대안 정답 그룹으로 유지한다. 새 LB 점수나 5-fold OOF 점수가 아니다.

- v3는 기존에 놓쳤던 GT 33개를 복구했지만, 기존에 찾던 GT 40개를 잃었다. 복구 수만 보고 개선으로 해석하면 안 된다.
- 작은 GT(원본 면적 670px 미만) 180개 중 최종 검출은 기존 103개, v2 96개, v3 103개다. v3의 핵심 목표였던 작은 객체의 최종 recall은 기존보다 늘지 않았다.
- v2 대비 v3는 FN을 15개 줄였지만 FP가 25개 늘었다. PQ 차이는 +0.000861에 그친다.
- 같은 물리 사진의 모든 주석자를 묶어 20,000회 paired bootstrap한 v3−v2 PQ 차이의 95% 구간은 **[−0.013507, +0.014452]**다. 뚜렷한 v3 우위로 해석하기 어렵다. v3−기존은 **[−0.038392, −0.009406]**다. 이는 반복 사용한 개발 validation 내 표본 불확실성 평가이며, 학습 seed 변동이나 LB 일반화 성능을 검증하지 않는다.

과거 기준선 PQ 0.472593과 이번 0.471930은 같은 수치가 아니다. 재계산 비교에서 86장에 마스크 차이가 있었으며, TP/FP/FN이 바뀐 사진은 `20120829063134Lh` 한 장이었다. 기존의 487px 예측 하나가 빠지면서 TP가 1 감소하고 FN이 1 늘었다. 다른 마스크의 작은 IoU 변화도 있다. **CSV만으로 실행 환경·수치 오차가 원인이라고 단정할 수 없다.** 이번 실험 간 비교는 이번에 함께 추론한 0.471930 기준선을 사용한다.

## 학습과 데이터 검사

- 두 군 모두 30에폭, 에폭당 실제 주석 레코드 1,053개 + 합성 이미지 263개를 사용했다.
- 두 군의 시작 YOLO, 해상도 2048, batch 1·누적 없음, LR·증강·runtime·소스 버전이 동일하다. 원래 native best84는 고정했다.
- optimizer 시도는 각각 39,480회다. AMP에 의한 생략은 v2 21회, v3 19회로 약 0.05%다. 심한 수치 불안정의 증거는 없다.
- v2 segmentation loss는 1.475→1.328, v3는 1.617→1.426으로 감소했다. 학습 완료와 loss 감소가 validation 개선을 보장하지는 않는다.
- 실제 학습·donor·배경에 validation 파일명이 포함되지 않았고, 실제 레코드 1,053개는 원래 train 분할과 일치했다.
- v3가 삽입한 526개 객체 중 393개(74.7%)가 hard pool이며, 면적 중앙값은 501.5px, 670px 미만은 392개다. 작은 어려운 객체를 보강하려던 샘플링은 실제로 작동했다.
- 합성 이미지 수는 군당 263장으로 같지만, 배경의 기존 라벨까지 포함한 합성 이미지 내 GT 수는 **v2 2,000개 / v3 2,450개**다. 이미지 비율만 통제한 비교이며 객체 수와 밀도까지 같지는 않다.
- 미리보기 6개 ROI에서는 삽입 구조와 마스크가 정렬됐고 뚜렷한 직사각형 접합 흔적이 보이지 않았다. 이는 전체 526개 객체의 품질 검증이나 FP 증가 원인 규명이 아니다.

두 추가 학습군이 모두 낮아졌기 때문에, 이번 하락을 새 합성 이미지의 품질만으로 설명할 수 없다. 공통 추가 학습 조건의 영향과 합성 방식의 영향을 분리할 실제 데이터만의 추가 학습 대조군이 아직 없다.

## 저장된 후보로 추가 실행한 진단

추가 GPU 학습 없이 업로드된 **YOLO 4개 기하학적 추론 뷰**를 사용했다. 저장 confidence ≥0.05, 후보 면적 ≥300px, strict IoU >0.5 기준으로 정답 후보 존재 여부를 계산했다. 이는 정답을 참고한 후보 존재 진단으로, 실제 선택 가능한 recall이나 최종 앙상블 점수가 아니다. 이전의 다른 후보 구성에서 측정한 92%와 직접 비교하지 않는다.

| 후보 존재 여부 | 기존 | v2 | v3 |
|---|---:|---:|---:|
| 저장된 후보 중 정답 후보가 있는 GT | 635/708 (89.69%) | 609/708 (86.02%) | 603/708 (85.17%) |
| confidence ≥0.30 후보 중 정답 후보가 있는 GT | 498/708 | 489/708 | 490/708 |
| 작은 GT의 정답 후보 존재, confidence ≥0.05 | 150/180 | 140/180 | 139/180 |

- v3는 저장된 후보 기준으로 기존에 없던 정답 7개를 추가했지만 기존에 있던 정답 후보 39개를 잃었다. 기존·v3 후보 합집합에는 642/708개의 GT에 대한 정답 후보가 있다. **합집합 후보가 있다는 이유로 FP 없이 그만큼 복구할 수 있는 것은 아니다.**
- confidence가 0.05 아래로 내려간 정답 후보는 이 자료에 없다. 따라서 후보 부재를 모델이 모든 confidence 범위에서 완전히 못 찾았다는 뜻으로 확대하지 않는다.
- 동일한 고정 mask NMS·픽셀 배분 규칙으로 confidence **0.05, 0.10, 0.15, 0.20, 0.25, 0.30, 0.35, 0.40, 0.45, 0.50, 0.60, 0.70**을 비교했다.
- YOLO 단독의 관찰된 최고 PQ는 기존 **0.432695 @0.35**, v2 **0.423989 @0.35**, v3 **0.416749 @0.30**이었다. 이 범위에서는 단일 confidence 임계값 변경으로 v3를 회복시키지 못했다.
- 임계값 탐색 결과는 같은 개발 validation에 맞춘 진단이다. 최종 앙상블의 모든 후처리 가능성을 검사한 결과가 아니며, 제출 설정을 자동으로 변경하지 않았다.
