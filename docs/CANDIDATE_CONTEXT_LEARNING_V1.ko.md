# 원영상 문맥 특징을 이용한 후보 선택기 학습 v1

## 평가 범위

- 기존 고정 분할의 train 616장으로 후보 선택기를 학습하고 validation 91장으로 평가한다. 검증 라벨은 학습·결측치 처리·조기 종료·보정에 사용하지 않는다.
- 원래 검출 모델의 가중치와 후보 마스크는 고정한다. 새로 학습하는 것은 CPU에서 실행하는 표 형태 특징 기반 후보 선택기다.
- 91장에는 주석 그룹 101개와 정답 객체 708개가 있다. confidence 0.30 대조군은 PQ 0.4309597847, FP 260, FN 255다.
- 이 코호트는 반복해서 사용한 개발 검증 데이터다. 새 데이터에서의 일반화 성능이나 public LB 개선을 입증하지 않는다.
- 앞서 기록한 707장 확장 후보군의 정답 존재율 92.01% 및 OOF PQ 0.436753과는 평가 범위가 다르다. 이번 수치를 서로 직접 비교하지 않는다.
- 이번 91장의 기존 YOLO·기하 변환 4개 뷰 후보(confidence ≥ 0.05, 면적 ≥ 300)에서는 GT 708개 중 635개(89.69%)에 IoU > 0.5 후보가 있다. 기존 FN 255개 중 해당 후보가 있는 것은 182개다. 이는 정답을 본 뒤 계산한 후보 존재율이며 실제 선택 성능이나 달성 가능한 recall 상한이 아니다.

## 입력 자료 확인

- 수신한 두 ZIP의 CRC, 전체 파일 해시, 분할 완전성, 공통 메타데이터 일치를 확인했다.
- 707개 사진별 캐시의 원본 train/validation 역할, 후보 순서, 체크섬, RLE 면적·bbox 및 confidence 특징을 확인했다. Validation 7,172개는 보유한 원본 후보 gzip과 RLE·confidence·target을 직접 대조했다. Train 53,535개의 원본 후보 gzip은 없어 출처·체크섬·geometry·정답 target 재계산까지 확인한 범위다. 이번 학습에는 전체 train 후보를 사용하며 이전 사진당 48개 제한을 적용하지 않는다.
- 전체 60,707개 후보의 target을 공식 정답에서 독립 재계산했다. 원래 float32 계산과 최대 차이는 약 8.3e-8이다.
- 원영상 문맥 특징은 102개다. 검토된 로컬 수집 코드와 업로드에 포함된 소스의 바이트 일치를 확인했으며, 업로드 소스를 실행하지 않았다.
- 원사진은 포함되지 않아 밝기·gradient 값 자체를 여기서 원영상으로 다시 계산하지는 못했다. 원영상 특징 값과 직접 확인한 RLE 면적·bbox·confidence 검증을 구분한다.

## 사전 고정한 학습 비교

- 두 모델 계열: HistGradientBoostingRegressor, ExtraTreesRegressor.
- 각 계열에서 첫 21개 confidence·형태·위치·유효 영역 특징과 전체 102개 특징을 비교한다. 추가 81개는 여러 스케일의 밝기·주변 대비·gradient·texture 통계다.
- 같은 계열의 두 모델에는 동일한 하이퍼파라미터, 동일한 후보, 동일한 가중치를 적용한다.
- 학습 목표는 주석자별 IoU > 0.5 일치 여부의 평균이다. 파일명·역할·원영상 해시·정답 값은 입력 특징에 포함하지 않는다.
- 사진마다 학습 가중치 합이 같도록 각 후보에 1 / 해당 사진 후보 수를 주고, 전체 후보 가중치 평균을 1로 정규화한다.
- HGB: 160회, 학습률 0.05, 최대 leaf 15, 최소 leaf 표본 100, L2 5, 조기 종료 없음.
- ExtraTrees: 160개 트리, 최대 깊이 12, 최소 leaf 표본 64, 전체 특징 사용. 결측치 처리기는 train에만 fit한다.
- Seed는 두 계열 모두 20261101이다. 검증 결과를 보고 하이퍼파라미터나 임계값을 추가 탐색하지 않는다.

학습/검증의 주석자 수 분포는 다르다. 학습 사진은 주석 그룹이 1/2/3개인 경우가 각각 329/137/150장이고, 검증은 82/8/1장이다. 다만 후보의 평균 일치 확률은 각각 0.4278/0.4256으로 가깝고 confidence별 조건부 평균도 비슷하다. 주석자 수 차이만으로 실패 원인이나 분포 이동을 단정하지 않는다.

## 후보 선택 규칙

각 모델에 다음 세 가지 규칙을 적용한다. c는 원래 confidence, q는 새 선택기의 예측 점수다.

- 순위만 변경: c ≥ 0.30 후보를 유지하고 0.75c + 0.25q로 순서를 정한다.
- 혼합 문턱: c ≥ 0.10이고 0.75c + 0.25q ≥ 0.30인 후보를 사용한다.
- 선택기 단독 진단: q ≥ 0.50인 후보를 사용한다.

Mask NMS, 최소 면적 300, 점수 순서에 따른 겹친 픽셀 배분은 기존 decoder를 그대로 사용한다. 모델 4개 × 규칙 3개로 새 설정 12개를 평가한다. 각 계열에서 대조군을 포함한 7개 예측 CSV를 모두 완성한 후 정답과 비교한다.

- 최대 recall은 ExtraTrees context102 혼합 문턱의 65.11%다. 기존 정답 2개를 잃고 새 정답 10개를 복구해 FN은 8개 줄었지만, FP가 46개 늘어 PQ가 하락했다.
- FP를 가장 많이 줄인 ExtraTrees context102 단독 점수 설정은 FP를 30개 줄이면서 기존 정답 23개를 잃고 8개를 복구했다. FN은 15개 증가했고 PQ는 0.430074로 기준선에 미달했다.
- 문맥 특징 추가 효과는 모델·규칙마다 방향이 달랐다. 같은 모델·같은 규칙의 context102 대 geometry21 비교 6개 모두 시간 블록 재표집의 PQ 차이 95% 구간에 0이 포함됐다. 이번 설정에서 일관된 개선을 확인하지 못했다.
- 작은 점수 차이를 새로운 데이터에서도 확실한 우열로 해석하지 않는다. 검증 데이터는 반복 사용했고, 보고한 구간은 여러 시도를 거친 선택 편향을 보정하지 않은 설명용 구간이다.
- 이번 학습 목표는 일치 여부의 확률이다. 같은 주석과 IoU 0.51인 후보와 0.95인 후보는 둘 다 일치한 것으로 학습하므로 실제 IoU의 크기 순위를 직접 학습하지 않았다. 결과는 이번 특징·목표·모델·규칙 조합에 대한 것이며 원영상 특징이나 품질 학습 전체의 무효성을 뜻하지 않는다.

## 독립 검증과 저장 자료

- 두 계열의 총 14개 CSV를 별도 구현으로 전부 재채점했다. Strict IoU > 0.5, 전체 일치 쌍 수와 고유 정답/예측 일치 수를 구분했고 PQ·FP·FN·IoU 합·정답 손실/복구가 원 결과와 일치했다.

- 학습된 모델 4개, 원순서 검증 점수, 코드, 설정, 제출 형식의 CSV, 지표를 보관했다. 새 신경망 추론이나 GPU 학습은 없었다.

- 기준선 FN 255개는 원시 후보에 정답이 없는 73개, 문턱에서 정답 후보가 모두 빠진 137개, NMS에서 정답 후보가 남지 않은 27개, 이후 픽셀 배분에서 정답 매칭을 잃은 18개로 구분됐다. 이 코호트에서 가장 큰 손실 지점은 후보 통과 조건이다.
- FN을 가장 줄인 ExtraTrees 문맥 혼합은 통과 후 정답 후보 존재를 498→519로 21개 늘렸다. 하지만 NMS 단계 손실은 27→29개, 픽셀 배분 손실은 18→29개로 늘어 최종 순 복구는 8개에 그쳤다. 최종 FP도 46개 늘었다.
- HGB 문맥 q 단독 설정이 기존 정답 29개를 잃은 위치는 통과 조건 21개·픽셀 배분 8개였다. ExtraTrees 문맥 q 단독의 기존 정답 손실 23개는 통과 조건 19개·NMS 1개·픽셀 배분 3개였다.
- 이번 7개 설정에서 픽셀 배분에 의한 정답 복구는 0개로 관측됐다. 일반적으로 복구가 불가능하다고 가정한 것은 아니다.
- 다음 방법을 고를 때는 낮은 confidence에서 정답 후보를 FP와 구별하는 능력, 그리고 새 후보가 기존 정답의 픽셀을 빼앗지 않는지를 함께 확인해야 한다. 이번 결과는 단순 문턱 완화나 개별 문맥 점수 대체만으로 그 문제를 해결하지 못했음을 보여준다.
