## 박스 개선이 왜 누락 감소로 그대로 이어지지 않았는가

같은 bbox와 바로 그 bbox에서 생성된 마스크를 연결해 확인했다.

- bbox IoU>0.5를 새로 통과한 GT는 88개이고 기존 통과에서 탈락한 것은 26개다. 순증이 62개다.
- 새로 통과한 88개 중 **49개는 이전에도 올바른 ROI 마스크 후보가 있었다.** 이들은 주로 위치 정확도가 개선된 경우다.
- 나머지 39개 중 25개가 새로 올바른 마스크 후보를 얻었고 14개는 여전히 부족했다.
- 전체 원시 ROI 후보에서는 42개를 새로 찾고 25개를 잃어 순증은 17개였다.
- bbox IoU>0.75를 새로 통과한 109개도 94개는 이미 올바른 마스크 후보가 있었던 객체다.
- DETR60의 정밀한 bbox(IoU>0.75)가 있는 256개 중 **245개는 동일한 bbox에서 만든 마스크도 IoU>0.5**였다. bbox 정확도를 더 높이는 방향은 여전히 근거가 있다.

추가로 confidence 0.05의 DETR60은 올바른 원시 마스크 후보 580개 → 품질·면적 필터 후 579개 → NMS 후 553개 → 픽셀 겹침 제거 후 최종 TP 487개다. 위치·크기 외에 후보 선택과 겹침 처리에서도 정답이 손실된다.

## 타일 검출의 효과

- DETR 타일 NMS 0.7은 bbox IoU>0.5 후보 존재율 637/708=89.97%에 도달했다.
- 하지만 91장에 18,058개 박스, 사진당 평균 약 198.4개를 생성해 설정한 최대 200개에 거의 도달했다. 주석 그룹별 bbox 오탐도 매우 많았다.
- 이 경로의 원시 ROI 마스크에는 정답 631개, 작은 정답 163/180개가 포함됐지만 실제 PQ는 낮았다.
- 9개 경로 전체의 원시 ROI 후보 합집합은 663/708=93.64%의 정답을 포함했다. 기존 전체 기준선 FN 221개 중 179개에 올바른 후보가 있었다.
- 이 수치는 정답을 조회한 후보 존재 진단이다. 잘못된 후보를 제거하고 겹치는 마스크를 처리할 수 있어야 최종 성능으로 이어지며, 93.64%의 실전 재현율을 달성했다는 뜻은 아니다.

## 업로드 후 추가한 36개 후처리 실험

- **기하 일치도 24개 규칙:** 검출 bbox와 예측 마스크의 bbox IoU, 마스크가 원래 bbox 안에 포함된 비율, 이를 이용한 후보 정렬을 비교했다. 특징 계산에 GT를 사용하지 않았다.
  - YOLO 최고: PQ 0.433735, FP 221, FN 274. 원래 0.433343에서 미세한 변화였다.
  - DETR60 최고: PQ 0.395057, FP 294, FN 290. FP 42개 감소와 함께 정답 17개를 잃었다.
  - 월별 보류 그룹에서 규칙을 선택하면 상승이 유지되지 않았다.
- **신규 후보 추가 12개 규칙:** DETR60·DETR 타일·YOLO 타일 후보를 기존 전체 기준선에 추가했다. 기존 마스크를 보존해 기존 TP 손실은 없었다.
  - 가장 좋은 실제 변경은 PQ 0.470208, FP 211, FN 220. 정답 1개 복구에 FP 7개가 늘었다.
  - 느슨한 DETR60 추가는 정답 19개 복구와 FP 172개 증가로 PQ 0.430320이었다.
  - 느슨한 DETR 타일 추가는 정답 34개 복구와 FP 518개 증가로 PQ 0.360164였다.
  - 월별 보류 그룹에서 기존 기준선을 포함해 선택하면 5개 그룹 모두 기존 기준선을 선택했다.
- 현재 추가 규칙을 제출 파이프라인에 채택하지 않았다. 모델 가중치나 기존 제출 코드도 변경하지 않았다.

## 추가 학습에 대한 판단과 다음 권장 실험

**DETR을 더 학습하는 것은 타당하다.** 이번에는 loss 하락뿐 아니라 같은 검증 조건에서 bbox 정확도와 오탐이 개선됐다. 60에폭에서 학습 효과가 없다고 판단해 중단할 근거는 없다.

- DETR60 가중치에서 누적 100에폭까지 추가 40에폭을 비교하는 것이 합리적이다. 80·100에폭에서 같은 해상도·고정 ROI·같은 평가 규칙으로 확인한다.
- 추가 단계의 학습률과 scheduler를 명시해야 한다. 완료된 고정 60에폭 실행의 숫자만 수정하는 것은 원래 스케줄의 단순 재개가 아니다.
- loss가 계속 내려가더라도 검증의 bbox IoU>0.75, 작은 객체, PQ·FP·FN이 멈추거나 악화되면 더 오래 학습하는 것만으로 해결되지 않을 수 있다.

**YOLO 추가 학습도 가능성은 있지만 별도로 확인해야 한다.** DETR의 개선을 YOLO의 개선 보장으로 일반화할 수 없다.

- 이전 YOLO 추가 학습 두 실험은 실데이터와 합성데이터를 함께 사용했고 전체 파이프라인 PQ가 약 0.447/0.448로 기존 약 0.472보다 낮았다. 합성데이터와 학습량 효과가 섞여 있어 추가 학습 자체가 항상 해롭다는 증거도 아니다.
- 이번에는 기존 YOLO 가중치에서 실데이터만 사용하고 낮은 학습률로 우선 20에폭 미세조정을 비교하는 편이 좋다.
- YOLO와 DETR을 각각 같은 고정 ROI U-Net으로 평가해 검출 개선을 비교한다. 두 모델을 동시에 바꾸어 앙상블 점수 하나만 보는 방식은 피한다.
- **DETR 추가 40에폭과 YOLO 추가 20에폭은 후속 제안이며 이번 업로드 이후 실행한 학습이 아니다.** 이번 로컬 작업은 결과 검증과 36개 캐시 후처리 실험이다.
