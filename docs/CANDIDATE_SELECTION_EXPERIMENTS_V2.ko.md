# 후보 선택 추가 실험 v2

같은 707장 OOF와 동결된 예측을 사용해 **출처별 근거 점수 4개 + 공통 참조 집합의 합의 순위 4개**, 총 8개 새 규칙을 시험했다. **모두 5개 fold 각각에서 기준선보다 PQ가 낮아 채택하지 않았다.** 모델 학습·신경망 추론·원본 가중치 변경은 없었다.

평가 범위는 707장, 주석 그룹 1,154개, GT 8,199개다. Native는 모든 fold 30epoch, YOLO는 30/30/30/30/25epoch이며, 과거 실험에 반복 사용한 개발 OOF다. 원래 고정 91장 평가나 public LB 결과와 직접 비교하지 않는다.

**기준선과 목표**

- 현재 기준선 `C4_then_C2`: PQ **0.436753**, 실제 recall **63.96%**, precision **64.46%**, FP **2,891**, FN **2,955**.
- 원시 후보 존재율 **92.01%**는 후보마다 GT와 대조한 진단이다. 실제 선택기의 recall이나 달성 가능한 성능의 보장이 아니다.
- 실제 recall 90%에는 최소 7,380개 GT 검출이 필요하다. 현재 기준선에서 2,136개를 더 찾아야 한다.

**실험 A: YOLO와 native의 점수 기여 분리**

이전 전체 재선택 점수를 `H = 0.8Y + 0.2N`으로 분해했다. Y는 YOLO 계열별 confidence·마스크 일치 근거, N은 일반 native와 TTA native의 일치 근거다. 두 값은 정답 확률로 보정된 점수가 아니다.

- S1: 기존 `H > 0.15` 통과 후보를 유지하고, 선택 순위를 `max(Y,N)`으로 변경.
- S2: 통과 조건만 `Y > 0.30 또는 N > 0.60`으로 바꾸고, 기존 H 순위를 유지.
- S3: 새 통과 조건과 `max(Y,N)` 순위를 함께 사용.
- S4: 새 통과 조건에서 `0.75 × max(Y,N) + 0.25 × min(Y,N)`으로 두 근거의 동의를 반영.
- 원시 후보군, 중복·포함 관계, 점수순 선택, 픽셀 배분은 동일하게 유지했다. 원래 마스크도 삭제·교체할 수 있다.
- 기존 기준선과 이전 G5 전체 재선택을 대조군으로 재현했다. 네 규칙과 두 대조군을 합쳐 CSV 30개를 생성한 뒤 GT로 평가했다.

|방법|PQ|Recall|Precision|FP|FN|복구 GT / 기존 GT 손실|
|---|---:|---:|---:|---:|---:|---:|
|현재 기준선|0.436753|63.96%|64.46%|2,891|2,955|0 / 0|
|이전 G5 대조군|0.346429|70.03%|40.75%|8,348|2,457|884 / 386|
|S1 순위만 변경|0.348276|70.48%|40.65%|8,437|2,420|905 / 370|
|S2 통과 조건만 변경|0.391822|67.45%|51.13%|5,285|2,669|681 / 395|
|S3 통과 조건 + 최대 점수 순위|0.395884|68.17%|51.24%|5,318|2,610|704 / 359|
|S4 두 근거의 동의 반영|0.397149|68.26%|51.37%|5,297|2,602|701 / 348|

- S1은 이전 G5 대비 정답 37개를 순증가시켰지만 FP도 89개 늘었다. 현재 최고 기준선과 비교하면 FP 증가가 훨씬 크다.
- S2의 G5 대비 PQ 상승은 FP 3,063개 감소와 FN 212개 증가가 함께 일어난 결과다. 후보를 더 정확히 복구했다는 의미로 해석하지 않는다.
- S4는 S3보다 FP 21개·FN 8개를 함께 줄였지만, 현재 최고 기준선을 대체할 수준은 아니다.

**가설 확인: native-only 점수 제한은 주요 원인으로 확인되지 않았다**

- 기존 최종 마스크는 물리적으로 4,999개다. 이 중 YOLO 지원 점수 Y가 정확히 0인 마스크는 **11개**였다.
- 기존 통과 조건과 새 조건 모두 그중 **3개만 통과**시켰다. 이번 데이터에서 native-only 복구 효과를 확인하지 못했다.
- 원시 마스크와 RLE가 완전히 같은 것이 없는 기존 마스크는 4,957개였지만, 대부분 주변의 유사한 YOLO 후보로부터 지원을 받고 있었다. “원시 마스크와 완전히 같지 않다”를 “YOLO 지원이 없다”로 간주하면 안 된다.
- 새 조건은 기존 통과 후보 225,018개 중 66,117개를 제외했고, 새로 통과시킨 후보는 없었다. 이 조건의 이득은 주로 선택을 보수적으로 한 효과였다.
- 따라서 이 구조적 점수 제한을 큰 병목이라고 결론 내리지 않는다. 같은 영역에서 좋은 대안을 고르는 문제는 여전히 남았다.

**실험 B: 동일한 다른 예측들에 대한 합의로 후보 비교**

기존 마스크와 같은 영역의 대안 후보를 비교했다. 평가에 사용하는 참조 집합은 두 마스크가 나온 source-view의 합집합과 두 마스크 자체를 모두 제외한 공통 집합이다. 두 마스크는 항상 동일한 참조·가중치로 채점했다.

- 각 추론 계열의 총 가중치를 같게 하고, 동일 view·동일 RLE의 반복으로 점수가 누적되지 않게 했다.
- 참조 계열이 2개 또는 view가 3개 미만이면 기존 마스크를 유지했다. 참조 부족을 낮은 품질 점수로 대신하지 않았다.
- 점수는 다른 예측들과 IoU > 0.5로 일치하는 정도다. 실제 GT에 대한 기대 IoU나 정답 확률이 아니다.
- 다른 기존 객체와 겹치는 픽셀을 제거한 실제 출력 모양을 채점했다. 원시 후보 면적의 5% 넘게 제거되면 거부했다.
- 객체 수는 유지하고 후보 마스크를 교체했다. 동시에 교체한 마스크끼리 충돌하면 관련 원본을 모두 복구했다.

|방법|PQ|Recall|FP|FN|복구 GT / 기존 GT 손실|
|---|---:|---:|---:|---:|---:|
|C1 매칭된 IoU의 합의 점수|0.419645|62.28%|3,029|3,093|243 / 381|
|C2 C1 + 충분한 점수 차이 요구|0.429545|63.15%|2,957|3,021|167 / 233|
|C3 IoU > 0.5 매칭 비율|0.408305|60.91%|3,141|3,205|206 / 456|
|C4 C3 + 충분한 점수 차이 요구|0.425857|62.68%|2,996|3,060|120 / 225|

- 가장 나은 C2도 정답 167개를 새로 찾는 동안 기존 정답 233개를 잃었다. 결과적으로 FP와 FN이 각각 66개 증가했다.
- 171,102개 원본–후보 쌍을 비교했다. C1은 마스크 4,664개를 변경했고, 보수적인 C2와 C4는 각각 1,497개와 717개를 변경했다. 변경을 줄여도 기존 정답 손실이 더 컸다.
- 많은 추론 결과가 비슷한 마스크를 지지한다고 해서 그 마스크가 GT에 더 가까운 것은 아니었다. 상관된 모델 예측의 합의만으로 정답 선택을 충분히 개선하지 못했다.

**독립 검증과 결과 보존**

- 실험 A 30개, 실험 B 25개 CSV를 각 실험에서 모두 생성한 뒤 GT로 평가했다. 결과를 보고 임계값을 추가 조정하지 않았다.
- 기준선 및 이전 G5 대조군의 CSV 바이트 일치, 이미지·가중치·코드 출처 해시, 최종 마스크 비중첩을 확인했다.
- 별도 작은 입력 검사 10개가 통과했다. 출처별 순위 변경, 엄격한 임계값 경계, 공통 참조 집합, 자기 투표·중복 view 처리, 빈 입력, 교체 충돌 복구를 포함한다.
- 두 실험군의 최고 PQ·최고 recall 방법, 기준선, G5를 별도 코드로 CSV에서 재채점해 일치함을 확인했다.
- 133개 시간 블록을 단위로 2,000번 paired bootstrap을 수행했다. S4의 기준선 대비 PQ 차이 95% 구간은 **−0.046649 ~ −0.032053**, C2는 **−0.011228 ~ −0.003098**였다. 각 방법은 5개 fold 모두에서 하락했다.
- 재표집 구간은 반복 사용한 개발 데이터의 변동을 나타내며, 과거 실험 선택의 영향을 교정하거나 리더보드 성능을 검증한 결과가 아니다.
- C2의 기존 정답 손실 233개와 복구 167개는 `selection_v2_consensus_case_audit.csv`에 기록했다. 이는 동결된 예측의 **사후 진단 목록**이며 validation 학습 샘플로 사용하지 않는다.

**현재 판단과 후속 실험 방향**

- 기준선 `C4_then_C2`를 유지한다. 이번 실험의 최대 recall 70.48%는 FP 폭증과 낮은 PQ를 동반하므로 채택하지 않는다.
- 기존 confidence와 예측 간 합의를 조합한 이번 규칙들에서는 실용적인 개선을 얻지 못했다. 이 결과만으로 모든 후보 선택 방법이 불가능하다고 결론 내리지는 않는다.
- 다음 검토 대상은 원영상의 주변 문맥과 기존·대안 마스크를 함께 비교하여 **교체의 이득과 기존 정답 손실을 예측하는 선택기**다. 학습이 필요하면 원래 고정 train 616장 / validation 91장 범위를 유지한다. 이번 턴에서 해당 새 모델 학습을 실행한 것은 아니다.
