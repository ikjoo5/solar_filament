# 후보 선택 다방면 실험 v3

이번에는 서로 다른 두 평가 범위를 분리해 비교했다. **707장 OOF의 디코딩 규칙 4개**, **고정 validation 91장의 품질 점수 혼합 18개**를 새로 평가했다. 91장 실험에는 confidence-only와 quality-only 대조 설정 10개가 포함되어 총 28개 설정을 실행했다. 새 구성은 모두 미채택이며, 현재 기준선을 유지한다.

추가 학습이나 신경망 추론은 하지 않았다. 실제 원영상 문맥 특징을 사용한 다음 학습 비교를 위해 별도의 CPU 수집 도구를 구현·검증했다. 전체 특징 수집과 새 선택기 학습은 아직 실행하지 않았다.

**A. 707장 OOF: 후보 점수는 고정하고 중복 제거·픽셀 배분만 변경**

- 707장, 주석 그룹 1,154개, GT 8,199개. Native는 모든 fold 30epoch, YOLO는 30/30/30/30/25epoch다.
- 원시 후보군과 기존 H 점수는 동결했다. 현재 최고 `C4_then_C2`와 이전 G1·G5를 대조군으로 재현했다.
- D1·D2: 기존 IoU/포함 관계의 충돌 그래프를 strict mask NMS IoU > 0.5로 변경했다.
- D3: Gaussian Soft NMS, sigma 0.5. 매 단계 감쇠된 점수로 순서를 다시 정하며, 통과 문턱 0.30은 그대로 유지했다.
- D4: 점수순으로 이미 선택한 픽셀을 제외하고, 원래 면적의 50% 이상과 최소 면적이 남는 후보만 채택했다. 거절된 후보는 픽셀을 차지하지 않는다.
- 출력 마스크는 기존 후보의 부분집합이다. 새 foreground 픽셀 생성이나 마스크 융합은 없었다. 픽셀 제외로 경계가 달라질 수는 있다.

|구성|PQ|Recall|FP|FN|
|---|---:|---:|---:|---:|
|현재 최고 기준선|**0.436753**|63.96%|2,891|2,955|
|이전 G1, cutoff 0.30|0.409498|65.01%|4,026|2,869|
|이전 G5, cutoff 0.15|0.346429|70.03%|8,348|2,457|
|D1: G1 + mask NMS 0.5|0.374119|64.78%|5,632|2,888|
|D2: G5 + mask NMS 0.5|0.288784|69.31%|12,580|2,516|
|D3: G1 + Gaussian Soft NMS|0.404910|65.03%|4,225|2,867|
|D4: G1 + 잔여 면적 50% 배분|0.390299|64.80%|4,845|2,886|

- D1·D3·D4는 같은 점수와 cutoff를 쓰는 G1과, D2는 G5와 비교했다. 새 규칙 모두 해당 대조군보다 5개 fold 각각에서 PQ가 낮았다.
- Soft NMS는 G1 대비 FN을 2개 줄이는 동안 FP를 199개 늘렸다. 억제를 완화한 D1·D2는 FP와 FN이 함께 증가했다.
- 후보가 더 많이 살아남아도 선행 마스크의 픽셀 점유와 최종 모양이 달라져 실제 정답 수가 늘지 않을 수 있다.
- GT 평가 전에 속도만 최적화했다. 거절될 후보를 RLE 교집합 면적으로 먼저 판정하고 통과한 후보만 픽셀로 변환했다. 실제 사진 3장 및 별도 경계 사례에서 이전 구현과 출력 RLE 순서·Counter가 완전히 같았다. 규칙과 임계값은 변경하지 않았다.

**B. 고정 91장: 기존 confidence를 유지하면서 학습 품질 점수를 보조로 사용**

- 원래 train 616장 / validation 91장 분할이다. 평가 주석 그룹 101개, GT 708개이며, 707장 OOF와 별도 비교다.
- 이미 학습된 품질 모델 epoch 18과 validation 원시 후보 7,172개를 동결했다. 새로운 학습·checkpoint 선택은 없었다.
- `0.9c+0.1q`, `0.75c+0.25q`, `c×(0.75+0.25q)`를 기존 cutoff 0.10 / 0.15 / 0.20 / 0.25 / 0.30에서 비교했다.
- 별도로 원래 confidence ≥ 0.30 후보를 고정하고, 위 세 점수로 순서만 바꾸었다. 후보 통과 조건 변화와 순위 변화의 영향을 분리했다.
- confidence-only·quality-only 대조군 각각 5개까지 합쳐 28개 설정을 모두 평가했다. 새로운 cutoff 탐색은 하지 않았다.

|구성|PQ|FP|FN|기존 정답 손실 / 새 복구|
|---|---:|---:|---:|---:|
|confidence 0.30 기준선|**0.430960**|260|255|0 / 0|
|가장 가까운 혼합: 0.9c+0.1q, cutoff 0.30|0.430879|243|263|10 / 2|
|고정 후보의 순위만: 0.9c+0.1q|0.425424|270|259|5 / 1|
|고정 후보의 순위만: 0.75c+0.25q|0.419040|278|265|12 / 2|
|고정 후보의 순위만: c×(0.75+0.25q)|0.424594|270|260|6 / 1|

- 최선 혼합의 PQ 차이는 −0.000081로 작다. FP가 17개 줄었지만 FN은 8개 늘었으므로 실제 recall을 높이는 목표에 맞지 않아 채택하지 않았다.
- 해당 차이의 시간 블록별 paired bootstrap 95% 구간은 −0.007939 ~ +0.007145다. 통계적으로 뚜렷한 악화라고 과장하지 않으며, 개선을 확인한 결과도 아니다.
- 원래 후보군을 고정한 순위 변경 3개는 FP·FN이 모두 증가했다. 품질 점수를 조금 섞는 것만으로 기존 정답 손실 문제를 해결하지 못했다.
- 91장은 품질 모델의 epoch 선택에도 사용된 개발 데이터다. 독립 검증 성능이나 전체 OOF 개선으로 해석하지 않는다.

**검증과 현재 결정**

- OOF 35개 CSV와 고정 91장 28개 CSV를 각 실험에서 모두 생성한 뒤 GT로 평가했다.
- 원시 후보 순서·RLE·confidence·품질 점수 연결, 입력·코드 해시, 최종 마스크 비중첩을 확인했다.
- OOF 기준선·G1·G5의 15개 대조 CSV와 고정 91장 confidence0.30·quality0.15의 CSV를 바이트까지 재현했다.
- 주요 후보와 대조군을 별도 코드로 재채점하고, 같은 사진의 주석 그룹을 함께 묶은 시간 블록 재표집으로 변동을 확인했다.
- 현재 채택한 OOF 기준선 PQ 0.436753과 기존 제출 구성을 유지한다. 이번 실험에서 recall 90%나 PQ 0.7을 달성하지 못했다.

**C. 다음 학습 비교를 위한 CPU 문맥 특징 수집 도구**

- 기존 Drive의 `fixed_split_experiments/mask_quality_v1` 원시 후보를 사용한다. Train 53,535개 / validation 7,172개 전부 포함하며, 이전 학습의 사진당 48개 제한을 적용하지 않는다.
- 102개 특징: confidence, 면적·종횡비·연결요소, 태양 반경 위치, 3개 스케일의 내부 밝기·주변 띠의 대비·gradient·texture 통계.
- 특징 계산 함수에는 정답 라벨·split 역할을 전달하지 않는다. 기존 target은 별도 필드에 보존한다. 이후 모델 입력은 명시된 feature columns만 사용한다.
- 원래 후보 RLE, 후보 순서, 사진·마스크·코드 해시를 함께 저장해 실제 PQ 평가와 연결할 수 있다.
- 사진·가중치는 내보내지 않는다. ZIP은 파일당 28 MiB 이하로 분할한다. 실제 전체 산출 시간·총용량·분할 개수는 아직 측정하지 않았다.
- 이미지 단위 캐시와 코드·설정을 Drive에 보관한다. 중단 후 최초 셀 또는 짧은 재개 셀로 완료 이미지를 검증해 재사용한다. 코드·데이터·라이브러리 버전이 바뀌면 캐시를 섞지 않고 오류를 낸다.
- 도구 기능 검사 10개와 별도 검토 사례 7개, 실제 원본 corpus metadata 검사가 통과했다. 전체 707장 특징 수집과 새 선택기 학습은 미실행이다.
- 이 환경에는 validation 후보 91장 캐시와 일부 이미지 패치만 있다. Train 616장의 원사진·후보 캐시는 Colab Drive에 있으므로 그곳에서 수집 셀을 실행해야 한다.

다음 데이터가 모이면 confidence-only 대조군을 포함해 원영상 문맥 특징의 추가 효과와 후보 간 교체 이득을 train-only 학습으로 비교할 수 있다. Validation과 외부 MAGFiLO 사진을 학습 데이터로 사용하지 않는다.
