# 실패 유형을 반영하는 합성 데이터 v3 설계

이 문서는 구현 전 가설과 예비 분석 기록이다. 이후 확정한 실행 조건과 재개 방법은 [Colab 실행 안내](TARGETED_SYNTHETIC_V3_COLAB.ko.md)를 따른다. 최종 비교는 같은 원본 YOLO에서 v2/v3를 각각 30에폭 추가 학습하며, 별도 real-only 마무리 구간은 사용하지 않는다.

## 목표와 현재 상태

사용자가 제안한 목적은 현재 잘 찾지 못하는 필라멘트의 특징을 학습 데이터에 보강하는 것이다. 이번에는 기존 설정을 확인하고 train 후보·정답으로 난이도를 분석했다. 새 합성 이미지 생성이나 추가 모델 학습은 아직 실행하지 않았다.

기존 best84 native 모델은 합성 v2의 462장·3,427개 객체를 crop 샘플 확률 20%로 사용했다. 따라서 단순히 합성을 처음 도입하는 실험이 아니라, 어려운 유형을 반영한 새 합성 방식의 추가 효과를 검증해야 한다. 이 20%는 확인된 native 학습 설정이며 과거 YOLO의 혼합 비율로 해석하지 않는다.

## Train에서 확인한 예비 난이도

자료는 기존 고정 train 616장, 주석 그룹 1,053개, GT 7,491개와 이전 YOLO 교사의 후보 53,535개다. Validation·test·외부 데이터·공개 노트북 payload는 분석이나 donor 선택에 사용하지 않았다.

후보의 최소 면적 300을 적용하고 strict IoU > 0.5로 나누면:

|분류|GT 수|
|---|---:|
|맞는 후보가 없음|646|
|맞는 후보가 있지만 모두 confidence < 0.30|1,319|
|confidence ≥ 0.30인 맞는 후보가 있음|5,526|

이는 **기존 YOLO의 후보 존재·통과 점수 진단**이다. NMS·픽셀 배분 이후의 최종 FN이나 현재 YOLO+native 앙상블의 FN 집계가 아니다. 학습 사진에서 관찰한 난이도이므로 독립 검증 성능으로도 해석하지 않는다.

- GT 면적 하위 25%(670px 미만)의 후보 부재·confidence 부족 비율은 40.9%다. 상위 25%는 20.3%다. 작은 객체를 우선 보강할 근거가 있다.
- 낮은 confidence 그룹의 GT 면적 중앙값은 857px, 충분한 confidence 그룹은 1,372px다.
- 태양 정규화 반경 0.8 이상 영역의 약한 후보 비율은 32.4%, 0.5 미만은 24.5%다. 크기 차이와 얽혀 있을 수 있으므로 위치만의 인과 효과로 단정하지 않는다.
- GT bbox 종횡비 중앙값은 그룹별 약 1.6~1.7로 비슷하다. 길쭉한 객체가 특히 어렵다는 가설은 현재 이 통계로 확인되지 않는다. Bbox 종횡비는 실제 필라멘트 굵기나 곡률을 직접 측정한 값도 아니다.
- 원사진 픽셀을 이용한 GT 대비는 아직 측정하지 않았다. 낮은 대비·가늘기·불연속성은 추가 영상 확인 항목이다.
- 면적 150px 이하 GT 19개는 예측 최소 면적 300 조건에서 IoU > 0.5가 불가능하다. 이 필터 제약은 합성 학습만으로 해결되지 않는다.

객체별 원본 파일명과 정답 ID를 포함한 목록은 `/workspace/artifacts/train_hard_filament_profile_v1.csv`, 전체 통계와 재현 코드는 동명의 JSON/Python 파일에 저장했다.

## 합성 방식

1. 기존 train의 실제 GT 필라멘트를 donor로 사용한다. 작은 객체와 낮은 confidence 정답 후보에 우선순위를 주되, 쉬운 객체와 다른 크기도 유지한다.
2. 먼저 어려운 실제 객체를 충분히 다시 학습하는 대조 방법을 고려한다. 실제 사례의 노출 부족과 합성 방식의 효과를 구분할 수 있다.
3. 실제 태양 배경의 밝기·질감·원반 위치를 고려해 donor를 합성한다. 단순한 직사각형 패치 경계가 학습 단서가 되지 않도록 주변 밝기와 대비를 맞춘다.
4. 크기·회전·완만한 형태 변형은 이미지와 정답 마스크에 동일하게 적용한다. 대비 변화는 실제 train 영상에서 측정한 범위를 기준으로 한다. 거의 보이지 않는 무작위 얼룩에 양성 라벨을 붙이지 않는다.
5. 배경에 원래 있던 객체의 라벨을 보존한다. 같은 사진의 서로 다른 주석자 결과는 대안 주석 그룹으로 유지하고, 임의로 하나의 정답 집합으로 합치지 않는다.
6. 가까운 두 객체를 합성하는 경우 인스턴스 ID와 간격을 보존한다. 특히 semantic U-Net의 foreground 합집합만으로는 맞닿은 두 인스턴스의 구분을 충분히 가르칠 수 없다는 점을 고려한다.
7. 흑점·원반 경계·거친 표면 등 헷갈리는 train 배경도 함께 학습한다. 모든 알려진 주석과 겹치는 부분을 잘못된 음성으로 만들지 않으며, 표본 미리보기로 미라벨 필라멘트와 합성 경계 아티팩트를 확인한다.

## 라벨과 저장 품질

- 고품질의 기준은 보기 좋은 이미지뿐 아니라 정답 마스크와 실제 삽입된 구조의 일치다.
- 새 합성 마스크는 binary mask/RLE를 기준으로 보존해 polygon 변환·rasterizer 차이에 따른 가는 구조 손실을 피한다. 기존 v2 loader와 공식 real GT rasterizer는 그대로 유지한다.
- 이미지별 donor·배경 파일명, annotation ID, 변환 값, seed, 원본·출력 해시를 저장한다.
- Synthetic에 유효한 spine 라벨이 없으면 native auxiliary spine loss에서 제외한다. 누락 라벨을 all-zero 정답으로 만들지 않는다.
- 이미지·라벨 캐시와 생성 설정을 별도 v3 폴더에 저장한다. 기존 데이터와 실험 checkpoint를 덮어쓰지 않는다.

## 학습 비교

이번 예비 분석에서 직접 측정한 약점은 **YOLO 후보의 작은 객체·낮은 confidence**다. 따라서 우선 같은 고정 분할의 원래 YOLO checkpoint에서 추가 학습을 비교하고 native best84를 고정하는 것이 해당 가설에 맞는다. Native만 바꾸면서 YOLO 자체 confidence가 개선됐다고 설명하지 않는다.

- 대조군: 같은 YOLO checkpoint에서 기존 합성 방식으로 추가 학습.
- 실험군: 같은 시작점에서 어려운 유형을 반영한 v3 합성으로 추가 학습.
- 두 분기의 실제/합성 샘플 비율, 추가 optimizer update 수, LR, 원영상 해상도, 쉬운/어려운 실제 샘플과 음성 배경의 비중, 마지막 real-only 학습 구간을 동일하게 고정한다. 20%를 적용한다면 새 YOLO 비교의 설정으로 명시하고 과거 설정을 재현했다고 주장하지 않는다.
- 어려운 실제 샘플을 더 자주 보여주는 효과를 분리해야 할 경우 동일한 real sampling을 유지한 채 합성 부분만 v2/v3로 교체한다. 비교 도중 여러 조건을 동시에 변경하지 않는다.
- 학습은 기존 train 616장에 한정한다. 원래 validation 91장에서는 공식 PQ·FP·FN·고유 GT recall과 크기별 결과를 비교한다.
- YOLO 단독 지표와 고정 native를 결합한 최종 파이프라인 지표를 모두 확인한다. 단독 개선이 최종 앙상블에서 사라지면 바로 채택하지 않는다.
- 이미 반복 사용한 개발 validation이므로 점수 상승을 새 리더보드 성능으로 단정하지 않는다. 첫 비교를 위해 5-fold 전체를 다시 학습하지 않는다.

실제 합성 이미지와 대비 범위 검사는 기존 Colab Drive의 원사진을 사용해야 한다. Cloud에 있는 특징·마스크 자료만으로 새로운 합성 영상의 품질까지 확인했다고 주장하지 않는다.
