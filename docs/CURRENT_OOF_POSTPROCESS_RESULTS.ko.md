# 현재 가중치의 전체 OOF 재평가와 16개 후처리 실험

2026-10-31 기준. `current_epoch_results_part01.zip`은 전체 자료를 담은 단일 ZIP이다.
223개 파일의 SHA-256·ZIP CRC와 예측 RLE·모델/입력 출처를 검증했다. 업로드된 Python은
데이터로 읽었으며 실행하지 않았다. 검토된 저장소 함수와 새 실험 스크립트만 실행했다.

## 평가 범위

- 물리 이미지707장·주석자별1,154그룹·정답8,199개 전체 OOF다.
- Native는 모든 fold30epoch, YOLO는30/30/30/30/25epoch다. 동일30epoch 예산이라고 표시하지 않는다.
- Strict IoU>0.5의 모든 qualifying pair를 global 합산했다. Fold PQ 단순 평균이 아니다.
- 동일 이미지의 주석자는 같은 fold에 묶여 있다. 새 가중치는 해당 fold 학습 자료에 한정된다.
- 실제 가중치 바이트는 이 ZIP에 없으므로, 이번 독립 검증은 저장된 추론·출처 기록을 재채점한 것이다.
- 예전91장 개발PQ0.472593과 현재707장 점수를 직접 같은 조건으로 비교하지 않는다.

## 추가16개 고정 규칙

새 학습·신경망 추론 없이 기존707장 캐시만 사용했다. 각 실험 묶음에서 후보 CSV를 모두
만든 뒤 GT로 채점했다. 기준 CSV는 원본과 바이트 단위로 같고 모든 후보 마스크는 비중첩이다.

## 최고 후보의 의미와 적용 상태

- 최고는 P1: **PQ0.433127851 / TP5173 / FP2843 / FN3026**.
- 기준0.431873883 대비 PQ+0.001253968, FP76개 감소·FN14개 증가다. 주효과는 FP 억제다.
- 제거 조건은 면적≤1000, 신뢰 native pool이 마스크의10% 미만을 덮음,
  IoU≥0.3으로 대응하는 원시 YOLO의 최대confidence<0.4를 모두 만족하는 경우다.
- 신뢰 native pool은 TTA0.35·area≥300·평균 출력≥0.8·4view 중2개가 면적의50% 이상 지지한다.
- 물리 마스크53개를 제거했다. 주석자별 평가에서는 FP76개 감소와 기존 GT14개 손실로 집계된다.
- 5개 fold 모두 PQ가 상승했고, 6관측소 중5개가 개선됐다.
- 물리 이미지 paired bootstrap2,000회의 조건부95% Δ구간은[+0.000510,+0.002030]이다.
  반복 선택 편향과 시간 상관을 제거한 독립 검증 구간은 아니다.
- **개발 후보로 보관하고 기존 고정 파이프라인을 자동 교체하지 않았다.**

## FN 복구를 우선한 결과

- YOLO Y1은 기존 마스크와 매칭을 유지한 채 FN90개를 복구했지만 FP251개가 늘어
  PQ0.430157068로 낮아졌다. Y2도FN40/FP113, Y3도FN19/FP51의 교환으로 악화됐다.
- 이 결과는 confidence와 여러view의 지지만으로 새 후보의 마스크 품질을 충분히 판별하지
  못했음을 보여 준다. Confidence 자체를 GT 마스크 IoU의 보정 확률로 해석하지 않는다.
- 새로운 경계 거리 평균의 최고는0.432001816(+0.000127933)으로 아주 작고,
  5fold 중2개만 개선됐다. 조건부95% 차이 구간[-0.000502,+0.000778]도0을 포함해 미채택이다.
- 따라서 이번 묶음에서 **FN을 줄이면서 FP 비용도 억제한 확실한 개선은 아직 찾지 못했다.**

## 미검출 원인과 다음 실험의 초점

- FN3012개 중1485개는 최종 예측과 겹침이0이다.618개는best IoU가0.4~0.5다.
- FN526개는 전체 예측foreground가 GT의80% 이상을 덮지만 개별 객체 매칭에 실패했다.
- 면적670픽셀 미만 GT2049개 중1059개를 놓쳤다. 작은 객체의 recall은 약48.3%다.
- 원시 YOLO/native 후보를 GT와 사후 대조하면 FN2478개(82.27%)에서 IoU>0.5 마스크가 있다.
  YOLO만1517개, native만32개, 둘 다929개이며 어디에도 없는 경우는534개다.
- 이는 실제2478개를 복구하거나 그만큼 복구 가능한 PQ를 달성했다는 뜻이 아니다.
  정답을 모르는 추론에서 후보 품질·객체 조립을 판별하는 것이 남은 문제다.
- 다음 우선순위는 confidence를 더 낮추는 반복보다 후보의 **예상 마스크 IoU·경계 품질**을
  구분하는 신호다. 학습을 수반하는 비교는 사용자와 정한 기존616/91고정 분할에서 별도로 수행해야 한다.
