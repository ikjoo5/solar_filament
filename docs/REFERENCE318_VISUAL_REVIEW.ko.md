## 대상 수

- 전체 공식 test는180장이다.
- 누락 후보 참조216개는100장, 형상 교체 참조102개는73장에 있다.47장이 두 집합에 공통이어서 원본 사진은 총126장이다.
- 고정318개 중 현재 자체 YOLO+best84 T4 기준선과 strict IoU>0.5로 대응하는 것은3개다. 기본 점검 대상은214+101=315개의 불일치 참조이고, 이들도126장에 걸쳐 있다.
- 여기서 참조는 public LB0.55의 공개 예측이다. 개별 정답 여부가 확인된 라벨이 아니며, 이 목록을 test 전체의 모든 FN으로 해석하지 않는다.
- 자체 파이프라인 LB0.39, 공개 예측을 섞은 혼합 제출0.45, 공개 원본0.55는 구분한다. 시각화는 자체 마스크를 바꾸거나 새 제출을 만들지 않는다.

## 볼 수 있는 그림

- 전체 사진 비교126장: 원본 / 이 사진의 고정 공개 참조 / 자체 최종 예측.
- 객체별 확대 비교318장: 원본 확대 / 공개 참조 마스크 / 같은 위치의 자체 최종 마스크 / 가장 유사한 자체 원시 YOLO 후보.
- 한 비교그림 안에 여러 패널이 있으므로 원본 사진 수와 생성되는 비교그림 수는 다르다. 총444개의 비교그림을 만들고, 기본 객체 뷰어는 불일치315개를 표시한다. 대응된 대조3개도 필터를 바꾸면 볼 수 있다.
- 공개 참조는 청록색, 자체 최종 마스크는 주황색, 원시 후보는 보라색으로 표시한다. 동일한 원본 좌표에서 잘라내고 종횡비를 유지한다.
- 마지막 패널은 공개 참조와 가장 높은 IoU를 갖는 원시 후보를 **진단 목적으로 고른 것**이다. 모델이 실제 채택한 후보라는 뜻이 아니다. 원시 후보가 최종에서 사라졌는지, 처음부터 형상이 다른지 판단하는 보조 정보다.
- 전체30뷰 원시 후보 중 참조와 IoU>0.5인 경우는274개다. 어떤 원시 후보도 겹치지 않는10개는 마지막 패널에 없음을 표시한다. 나머지는 부분적으로 겹치는 최상위 후보를 보여준다.
- 확대 그림 밖으로 마스크가 이어질 수 있다. 해당 그림의 crop 좌표와 전체 사진을 함께 확인한다.

## 흑점 추가 학습의 판단

- 확인된 흑점 오검출이 있다면, 그 예제를 hard negative로 추가하는 방식은 타당하다. 필라멘트와 혼동하는 흑점의 어두운 중심·주변 구조를 모델이 구별하도록 유도할 수 있다.
- 현재 어두운 오검출을 전부 흑점이라고 확인한 것은 아니다. 흑점, 미세한 표면 무늬, 마스크의 과도한 확장, 객체 분리 오류 등을 먼저 나누어 봐야 한다.
- 기존 segmentation 학습도 원칙적으로 미표기 배경을 음성으로 보지만, 드물고 어려운 흑점 사례가 충분히 노출되지 않으면 명시적인 음성 표집이 도움이 될 수 있다.
- 학습 예제는 원래 train616장 안에서 찾는다. 정답 마스크와 육안 점검을 함께 사용해 흑점 주변의 실제 필라멘트를 음성으로 지우지 않는다. 애매한 사례는 확인 전까지 음성으로 강제하지 않는다.
- 우선 기존 필라멘트 양성과 함께 흑점 hard negative의 노출을 늘린 대조 실험을 한다. 별도 흑점 분류 head를 더하는 것은 그 다음 비교 대상으로 둘 수 있다. 모든 둥근 어두운 물체를 삭제하는 규칙을 의미하지 않는다.
- 평가에서는 전체 PQ·FP·FN과 흑점으로 확인된 FP의 변화를 함께 본다. 흑점 FP가 줄어도 진짜 필라멘트를 놓치면 전체 이득이 없을 수 있다.
- 이번 test 시각 점검의 메모는 오류 유형 파악과 후속 실험 설계용이다. 이를 숨겨진 정답으로 간주해 모델 학습에 자동 투입하지 않는다.

## 사람이 메모할 때 유용한 항목

- 흑점 의심 / 필라멘트처럼 보임 / 표면 미세 구조 / 마스크 범위 차이 / 객체 분리·병합 차이 / 판별 어려움.
- 원시 후보는 적절한데 최종에서 빠졌는지, 최종 위치는 맞지만 크기·모양이 다른지, 원시 후보도 없는지.
- 근처 흑점이나 밝은 영역, 약한 대비, 짧거나 끊어진 형태처럼 다음 train 예제를 찾는 데 쓸 수 있는 특징.
- 육안 판정도 공식 test 정답을 대신하지 않으므로 `의심`과 `확인`을 구분해 기록한다.
