# CHASE와 대회 GONG 입력의 차이

작성일: 2026-11-04. 사용자 선택에 따라 SWEFil은 이번 실험 대상에서 제외하고 CHASE를 우선 검토한다. 사용자가 확인한 주최 측 외부 데이터 허용 회신을 따른다. 추가 데이터로 인한 PQ 상승은 아직 측정하지 않았다.

## 사용자 확정 범위

- CHASE에서 필라멘트의 형태·명암·경계 특징을 학습한다. right/left chirality 분류는 학습 목표에 포함하지 않는다.
- 최신 사용자 지시에 따라 겹침이 자료에 명시된 경우만 제외한다. 명시가 없으면 학습한다. 교차·가지·연결 영역 크기 등의 자동 제외 규칙은 사용하지 않는다.
- 공개 이진 마스크에는 원래 객체별 ID가 없으므로 실제 겹침을 완전하게 자동 판별할 수 없다. 명시적 제외 영역은 loss-ignore 또는 YOLO 전체 관측 제외로 처리하고 필라멘트 픽셀을 배경 정답으로 바꾸지 않는다.
- 이번 추가 학습에는 CHASE만 사용하며 GONG replay와 마지막 GONG 보정 학습은 생략한다. GONG으로 다시 학습하는 선택은 향후 최종 모델 단계에서 검토한다. 최종 출력 마스크의 픽셀 겹침 금지를 유지한다.
- 추가 학습 대상은 기존0.39파이프라인의 YOLO와 best84 둘 다다. 각각 이어 학습하고 기존/새 조합4개를 평가한다. [실행 설계](CHASE_BOTH_TRAINING.ko.md)를 따른다.

## 확정한 CHASE 입력 전처리

- 사용자의 최신 선택에 따라 **원반 정렬만** 적용한다. 앞서 제안했던 약한 밝기 평탄화 비교도 이번 기본 실험에서 제외한다.
- 배포 PNG에서 원반 중심·반지름을 추정해 GONG 기준 좌표의 중심과 크기에 맞춘다. 평행이동과 동일 비율 확대/축소를 사용하고, 가로·세로를 다르게 늘리는 비선형 형태 변형은 하지 않는다.
- 영상과 마스크에는 같은 좌표 변환을 적용한다. 영상은 축소 시 적절한 보간/안티앨리어싱을 사용하고 마스크는 nearest-neighbor로 변환한다. 원본 파일과 원래 마스크는 보존한다.
- CHASE에 추가 limb darkening 보정, CLAHE, percentile stretch, gamma/대비 변화, sharpening, blur, black-hat, 학습 기반 초해상도를 적용하지 않는다. 밝기·흐림 증강도 이번 조건에서는 사용하지 않는다.
- 모델이 요구하는 uint8→float 스케일 변환, 흑백3채널 복제 및 기존 encoder의 고정 mean/std 정규화는 유지한다. 이는 국소 대비나 경계 모양을 바꾸는 영상 보정이 아니라 모델 입력의 수치 표현이다.
- 정렬 자체에도 보간이 포함되므로 가는 마스크·원반 가장자리 보존을 점검한다. 원반 추정에 실패한 영상을 임의 값으로 강제 변형하지 않는다.
- 이 선택의 적용 범위는 CHASE 추가 학습 입력이다. GONG 검증은 기존 전처리 조건을 유지해 CHASE 추가 효과와 GONG 전처리 변경 효과가 섞이지 않도록 한다. GONG 학습 이미지는 이번 추가 학습에 사용하지 않는다.

## 관측 방식

| 항목 | 대회 GONG | CHASE |
|---|---|---|
| 위치 | 여러 지상 관측소 | 우주 위성 |
| 대기 영향 | seeing·구름·관측소별 편차가 있음 | 지구 대기의 seeing·구름 영향이 없음. 다른 장비 잡음·광학 한계는 남음 |
| H-alpha 관측 | 중심6562.8 Å의 필터 영상. 관측소별 대역폭 약0.5~0.6 Å | HIS가 H-alpha 주변의 스펙트럼을 측정. 파장 샘플 간격0.024 Å |
| 명목 공간 해상도 | NSO 설명 약2 arcsec | 연구팀 설명 약1.2 arcsec |
| 시간 구성 | 전 원반 영상. 약1분/관측소 | 슬릿 raster scanning으로 전 원반을 약46초~1분에 수집 |
| 이번 학습용 파일 | MAGFiLO의2048×2048 JPEG | 실제 확인한 AHAS/MHAS 샘플은2048×2048,8-bit grayscale PNG |

- 파장 샘플 간격과 필터 대역폭은 서로 다른 물리량이다. 0.024와0.5를 나눠 공간 해상도나 사진 품질 배수로 해석하지 않는다.
- CHASE의 명목 공간 해상도와 지상 seeing 부재는 유리하지만, 공개 PNG가 GONG보다 픽셀 수가 큰 것은 아니다. 실제 해상도는 관측 모드, binning, 출력 변환, 광학 PSF 등의 영향을 받는다.
- 좁은 파장에서의 H-alpha 강도와 넓은 필터를 통과한 강도는 다르다. 같은 필라멘트라도 움직임에 의한 Doppler shift와 필터 대역폭에 따라 어두움·폭·가시성이 달라질 수 있다.
- CHASE의 continuum/Fe I 등 다른 채널과 H-alpha 채널을 혼동하지 않는다. 이번 공개 분할 데이터의 H-alpha 이미지를 검토했다.
- CHASE가 별도 시각·관측에서 얻은 영상이면 GONG의 같은 사진을 선명하게 만든 정답 쌍이 아니다. 이것만으로 GONG→CHASE 초해상도 지도학습 쌍을 만들 수 없다.

## 실제 파일에서 확인한 내용

HTTP Range로 ZIP 중앙 디렉터리와 필요한 멤버만 받아 CRC를 검증했다. 전체1.2GB 자료는 다운로드하지 않았다.

| 자료 | 확인한 이미지 | 영상 | 마스크 |
|---|---|---|---|
| AHAS | `RSM20240101T061747_0000_HA.png` | 2048×2048, uint8, grayscale | 2048×2048, 픽셀값0/255 |
| MHAS | `01.png` | 2048×2048, uint8, grayscale | 2048×2048, 픽셀값0/255 |

- 확인한 마스크는 **필라멘트/배경의 semantic binary mask**다. 각 필라멘트의 instance ID가 없다.
- MHAS는120장으로, k-means 초기 라벨을 수동 교정한다. 원 논문은 활동영역 위의 어두운 필라멘트 보완, 같은 filament channel의 파편 연결, 희미한 경계 수정 등을 설명한다.
- AHAS는2024~2025년 관측695장과 MHAS120장의 재라벨을 합친815장이다. 모델·DenseCRF·hole filling 이후 사람이 선별한 라벨이다. 모든 픽셀이 독립적으로 수동 검증됐다는 뜻은 아니다.
- MHAS120장과 AHAS에 포함된120장은 같은 관측이므로 독립적인935장으로 합산하지 않는다. 원 관측 기준으로 분할·표집한다.
- 두 샘플의2048 크기 확인을 데이터셋 전체 모든 파일 검증으로 확대 해석하지 않는다. 전체 준비 단계에서 파일별 크기·형식·무결성을 다시 검사해야 한다.
- 실제 비교 그림: `/workspace/artifacts/chase_comparison_20261104/chase_samples_preview.png`. 제공 PNG 밝기를 유지했고 원본 crop과 공개 마스크를 나란히 표시했다. 확인한 두 표본의 원반 반지름은 약940픽셀로 GONG 전용900픽셀과 다르다. 실제 학습에서는 원반 형상을 별도 추정/정렬한다.

## 우리 모델에 연결할 때

1. CHASE 영상의 태양 원반 중심·반지름을 추정해 GONG 기준으로 정렬한다. 위 확정 조건에 따라 추가 명암 보정은 하지 않는다. 정렬 전에 GONG용 반지름900으로 잘라내지 않는다.
2. U-Net의 encoder와 foreground segmentation을 학습하는 자료로 우선 활용한다. binary mask에서 연결 성분을 추출해 임의로 대회 instance GT라고 부르는 방법은 피한다. 하나의 필라멘트가 끊겨 있거나 여러 객체가 닿아 있을 수 있다.
3. native 모델의 spine 등 별도 head는 해당 외부 데이터에 같은 정의의 정답이 없다면 외부 샘플에서 그 loss를 생략하거나 별도 검증된 생성 규칙을 둔다. 무조건 기존 두 head에 동일한 정답이라고 입력하지 않는다.
4. CHASE의 자동 라벨과 대회 수동 라벨을 동일 품질이라고 가정하지 않는다. 현재 사용자가 선택한 CHASE-only 추가 학습부터 평가한다. GONG 추가 미세조정이나 혼합 대조군은 향후 선택지이며 이번 실행에는 포함하지 않는다.
5. 새 모델 비교는 기존 고정 validation에서 시작한다. 현재는 기존 가중치 대비 CHASE 추가 학습의 효과를 확인한다. 동일 예산의 GONG-only 대조군을 실행하지 않으므로 그 방식보다 우월하다고 단정하지 않는다. validation은 external mask 학습이나 정답 수정을 위한 입력이 아니다.
6. 실제 PQ·TP·FP·FN과 작은/저대비 객체 검출을 평가한다. CHASE semantic IoU/Dice 상승을 대회 instance PQ 상승으로 대신하지 않는다. 공개 참조216+102는 별도 후보 포함률 진단으로 유지한다.

이번 단계에서는 공개 표본 이미지/라벨과 관측 설명을 확인했으며 GPU 추가 학습·PQ 계산은 실행하지 않았다.
