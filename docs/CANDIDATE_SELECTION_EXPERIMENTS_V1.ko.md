# 92% 후보군에서 실제 정답을 선택하는 실험

707장 OOF의 기존 후보군을 다시 사용해 **전체 재선택 6개 + 기존 결과를 기준으로 한 국소 교체 4개**, 총 10개 규칙을 평가했다. 추가 모델 학습이나 신경망 추론은 수행하지 않았다. 이번에는 기존 오검출도 제거·교체할 수 있도록 하여, 앞선 실험의 “기존 마스크를 전부 보존한다”는 제약을 해제했다.

현재 기준선을 대체할 방법은 얻지 못했다. 가장 높은 실제 재현율은 **70.03%**였지만 FP가 크게 늘어 PQ가 하락했다. 작은 중복 통합에서만 PQ가 0.000102 상승했으나 FN이 증가했고, 시간 블록별 변동을 고려하면 안정적인 개선 근거가 부족했다. 새 규칙 10개 모두 미채택이다.

**이번 비교의 기준**

- 같은 707장 / 주석 그룹 1,154개 / GT 8,199개에서 평가했다.
- 기준선 `C4_then_C2`: PQ **0.436753**, 재현율 **63.96%**, precision **64.46%**, FP **2,891**, FN **2,955**.
- “후보 안에 정답이 92.01% 존재”는 기본·전처리·타일 추론 후보에 대해 confidence ≥ 0.05, 면적 ≥ 300으로 제한한 뒤 GT별로 IoU > 0.5 후보를 찾은 결과다. 실제 선택기의 재현율이 아니다.
- 실제 재현율 90%에는 최소 7,380개 GT 검출이 필요하다. 기준선보다 2,136개를 더 찾아야 한다.
- Native 모델은 5개 fold 모두 30epoch, YOLO는 30/30/30/30/25epoch다. 이번 비교에서 가중치는 변경하지 않았다.
- 기존에 반복 사용한 개발 OOF다. 실제 test 또는 public LB 성능을 측정한 결과가 아니다.

**전체 후보 재선택: 기존 오검출도 삭제·교체**

- 원시 후보와 기존 최종 마스크를 함께 놓고, 마스크가 중복되거나 작은 마스크를 대부분 포함하는 관계를 계산했다.
- 후보의 근거 점수는 YOLO confidence, 기하 변환·전처리·타일 계열별 일치도, 일반 native와 TTA native의 일치도를 조합했다. 같은 계열의 뷰 개수가 많다는 이유만으로 점수가 누적되지 않도록 했다.
- 높은 점수의 후보부터 겹침을 확인해 선택하는 방식과, 이미 선택한 하나를 서로 겹치지 않는 후보 둘로 교체하는 방식을 비교했다.
- 후보를 한 개 더 선택할 때 적용하는 비용을 0.15 / 0.30 / 0.40으로 비교했다. 비용 0.15 대조군은 낮은 confidence 정답의 탈락을 확인하기 위해 **평가 전에** 추가했다. 이 근거 점수는 정답 확률로 보정된 값이 아니다.
- 경계 융합이나 마스크 재학습은 하지 않았다. 선택된 후보 사이에 남은 픽셀 겹침만 정해진 순서로 배분했다.

|방법|PQ|재현율|Precision|FP|FN|새로 복구 / 기존 정답 손실|
|---|---:|---:|---:|---:|---:|---:|
|기준선|0.436753|63.96%|64.46%|2,891|2,955|0 / 0|
|G1: 비용 0.30, 점수순 선택|0.409498|65.01%|56.96%|4,026|2,869|530 / 444|
|G2: G1 + 하나를 둘로 교체|0.408213|64.92%|56.67%|4,069|2,876|536 / 457|
|G3: 비용 0.40, 점수순 선택|0.415610|58.01%|65.15%|2,543|3,443|310 / 798|
|G4: G3 + 하나를 둘로 교체|0.415804|58.04%|65.17%|2,543|3,440|313 / 798|
|G5: 비용 0.15, 점수순 선택|0.346429|70.03%|40.75%|8,348|2,457|884 / 386|
|G6: G5 + 하나를 둘로 교체|0.342027|69.64%|40.04%|8,548|2,489|903 / 437|

- G5는 정답 884개를 새로 맞혔지만 기존 정답 386개를 잃어 순증가는 498개였다. FP는 **5,457개 증가**했다.
- G6는 새로 복구한 정답 수가 903개로 가장 많았지만 기존 정답 손실도 437개로 커졌다. “복구 수”만으로 선택기의 성능을 평가할 수 없음을 다시 확인했다.
- 높은 비용은 FP를 줄였지만 FN을 늘렸다. 낮은 비용은 FN을 줄였지만 FP를 크게 늘렸다.
- 이번 점수식에서 YOLO 계열의 지원이 전혀 없는 후보는 native의 기여만으로 최대 0.2점을 받는다. 따라서 비용 0.30/0.40에서는 native만 지지하는 기존 후보도 제외된다. 이는 이번 점수식의 제약이며, 기존 후보 교체 자체가 불가능하다는 결론을 뜻하지 않는다.
- 전체 재선택 6개 모두 5개 fold 각각에서 PQ가 하락했다. 충돌 관계를 처리하는 것만으로 좋은 후보를 안정적으로 구별하지 못했다.

**국소 교체: 더 강한 근거가 있을 때만 변경**

- 기존 결과를 기준으로 단일 객체 교체, 객체 하나를 둘로 분리, 둘을 하나로 통합, 세 방식의 조합을 비교했다.
- 서로 다른 raw 계열 두 개 이상과 일반 native·TTA native가 후보를 지지할 때만 변경했다. 기존 객체보다 근거 점수가 충분히 높아야 하며, 교체 대상이 아닌 기존 객체의 픽셀은 보존했다.
- 서로 다른 native 객체가 지지하는 후보 쌍만 분리 대상으로 사용했다. 변경 후 마스크의 픽셀이 원시 후보의 5%를 넘게 제거되면 교체를 거부했다.

|방법|PQ|재현율|Precision|FP|FN|새로 복구 / 기존 정답 손실|
|---|---:|---:|---:|---:|---:|---:|
|L1: 하나를 다른 후보 하나로 교체|0.434096|63.46%|63.95%|2,932|2,996|158 / 199|
|L2: 하나를 둘로 분리|0.436177|64.30%|63.91%|2,976|2,927|71 / 43|
|L3: 둘을 하나로 통합|0.436855|63.92%|64.52%|2,881|2,958|1 / 4|
|L4: 교체·분리·통합 조합|0.434271|63.68%|63.79%|2,963|2,978|181 / 204|

- L2는 FN 28개 감소에 FP 85개 증가로 PQ가 하락했다.
- L3는 물리적 통합 9건에서 FP 10개를 줄였지만 FN이 3개 늘었다. PQ 차이 +0.000102의 시간 블록 단위 재표집 95% 구간은 **−0.000308 ~ +0.000504**로, 상승만을 지지하지 않았다.
- 이 구간은 같은 개발 데이터 안의 변동을 나타낸다. 과거 반복 튜닝이나 여러 방법 중 선택한 영향을 교정하지 않았으므로 독립적인 일반화 검증으로 사용하지 않는다.

**92%의 후보가 어디에서 탈락했는가**

가장 높은 실제 재현율을 보인 G5의 선택 코드와 CSV를 동결한 뒤 사후 진단했다. GT는 각 단계에서 유효한 후보가 남았는지 확인하는 용도로만 사용했다. **최종 CSV 이전 행은 GT별 후보 존재량이며, 동시에 달성 가능한 재현율이나 실제 검출 실적이 아니다.**

|단계|IoU > 0.5 후보가 남은 GT|전체 GT 대비|기존 FN 2,955개 중 해당 GT|
|---|---:|---:|---:|
|원시 후보|7,544|92.01%|2,306|
|기존 최종 마스크도 후보로 포함|7,550|92.08%|2,306|
|근거 점수 필터 통과|7,115|86.78%|1,872|
|겹침을 고려해 후보 선택, 픽셀 배분 전|5,767|70.34%|894|
|최종 CSV의 실제 매칭|5,742|**70.03%**|**884**|

- 원래 보고했던 **7,544개 / 8,199개 = 92.01%**를 동일 원시 후보에서 다시 재현했다.
- 점수 필터에서 유효 후보가 사라진 GT는 **435개**였다. 그중 434개가 기존 FN이었다.
- 그다음 겹치는 후보 중 남길 것을 고르는 단계에서 **1,348개**의 GT가 유효 후보를 잃었다. 기존 FN 978개와 기존 TP 370개가 포함된다. 이번 선택기에서는 이 단계의 손실이 가장 컸다.
- 마지막 픽셀 배분은 30개를 잃고 5개를 새로 맞혀 순손실 25개였다. 경계·겹침 처리도 영향을 주지만 이번 재현율 손실의 대부분을 설명하지는 않았다.
- 이후 비교에서는 **같은 영역의 대안 후보 중 정답에 가까운 대표를 고르는 점수·순서**, 모델 출처에 따른 점수 차이, 기존 정답 손실을 함께 다룰 필요가 있다. 단순히 후보 간 충돌을 없애는 것과 올바른 후보를 선택하는 것은 다르다.
- 진단 과정에서 다시 만든 최종 G5 CSV 5개는 동결된 실험 CSV와 바이트까지 같았다. 결과를 보고 예측을 변경하지 않았다.

**검증 방법**

- 전체 재선택 35개 CSV, 국소 교체 25개 CSV를 각 실험에서 모두 생성한 후 GT 평가를 수행했다. 평가 결과를 보고 규칙이나 임계값을 다시 변경하지 않았다.
- 원시 후보의 이미지·모델·코드 해시, fold별 데이터 범위, 기존 기준선 CSV의 바이트 일치, 최종 마스크 비중첩을 검사했다.
- 별도 검토 코드의 작은 입력 사례 8개가 통과했다. family별 confidence 분리, 하나를 둘로 교체할 때의 외부 충돌, 국소 교체 간 충돌, 누적 픽셀 제거 제한, 빈 입력을 포함한다.
- 기준선과 두 실험군의 최고 PQ·최고 recall 구성을 별도 코드로 CSV에서 다시 채점해 일치함을 확인했다.
- 공식 PQ는 IoU > 0.5인 모든 매칭 pair와 전체 FP/FN을 합쳐 계산했다. Recall과 precision은 고유 매칭 GT와 예측 수를 사용했다.
- 원래 OOF의 시간 블록 133개를 단위로 2,000번 paired bootstrap을 수행했다. 같은 사진의 여러 주석 그룹은 항상 함께 재표집했다.

**현재 판단**

- 후보 생성 이후의 선택 단계에 개선 여지가 있지만, 이번 confidence·계열 간 일치·native 지원 조합으로는 정답을 충분히 구분하지 못했다.
- 기존 예측을 무조건 보존하면 좋은 후보가 막히고, 전체를 자유롭게 바꾸면 기존 정답을 잃는다. 이후 선택기는 두 비용을 함께 다루어야 한다.
- 현재 채택한 기준선은 변경하지 않았다. 이번 실험에서 실제 재현율 90% 또는 PQ 0.7을 달성하지 못했다.
