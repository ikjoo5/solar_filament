# 현재 5-fold 개발 기준선

기존 `C4_then_C2` 뒤에 동결된 R1 꼬리 복원을 **한 번** 적용한 결과를, 다음 5-fold 후처리 실험의 비교 기준선으로 채택한다.

- 기준 PQ: **0.43766947699238606**.
- TP **5,256**, FP **2,879**, FN **2,943**.
- 이전 기준선 대비 PQ **+0.000916969**, FP·FN 각각 **12개 감소**.
- 707장 전체 OOF에서 5개 fold 중 4개가 상승했다. 독립 재채점과 4,999개 출력 마스크의 추론 모듈 재현 검사를 통과했다.
- 기존 `C4_then_C2`의 PQ 0.436752508 결과는 과거 대조군으로 보존한다.

정확한 fold별 예측 경로·SHA와 코드 SHA는 [기준선 설정](/workspace/solar_filament/configs/oof_reference.json)에 고정했다. 기존 OOF에는 이미 R1이 적용된 CSV가 있으므로 추가 학습이나 GPU 추론 없이 그 결과를 비교 기준으로 사용한다. 이미 복원된 마스크에 R1을 다시 적용하지 않는다.

이 결정은 **5-fold 개발 기준선 채택**이다. 반복 사용한 OOF이며, native는 모든 fold 30epoch, YOLO는 30/30/30/30/25epoch다. 독립 평가나 public 성능 추정으로 해석하지 않는다.

고정91장 best84에 동일한 규칙을 적용한 결과는 PQ +0.000111957, FP·FN 변화 0이었고 불확실성 구간에 0이 포함됐다. 따라서 best84 제출 파이프라인 또는 public 0.55 RLE에 대한 채택은 별도 결정으로 남긴다. 이 전이 결과는 OOF 개발 기준선을 올리는 것을 막는 이유는 아니다.

실험 당시의 `adopted: false`와 원본 보고서는 역사적 기록으로 유지하며, 후속 OOF 비교에는 이 문서와 기준선 설정의 결정이 우선한다.
