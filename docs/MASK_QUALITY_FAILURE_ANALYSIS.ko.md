# 후보군에 정답이 있는데도 품질 모델 PQ가 낮아진 이유

## 핵심 판단

- **좋은 후보가 이미 존재하므로 후보 선택만 개선해도 큰 성능 향상이 가능하다는 방향은 타당하다.** 이번 품질 모델 하나의 실패가 이 가능성을 부정하지 않는다.
- 후보 존재는 정답으로 대조한 잠재 신호다. 실제 알고리즘은 정답을 보지 않고 좋은 후보·나쁜 후보·중복 후보를 구분해야 한다.
- 새 raw ZIP으로 confidence와 품질 점수의 기존 결과를 모두 정확히 재현했다. 실제로 새 품질 모델은 기존 FN 중 **57개를 복구했지만 기존 TP 127개를 잃었다**. 순 TP 70개 감소와 FP 166개 증가가 PQ 하락으로 이어졌다.
- 요청에 따라 **새 혼합 점수, 새 threshold, 새 학습을 시험하지 않았다.** 아래 내용은 기존 두 결과의 재현 및 실패 원인 진단이다.

## ‘1,965개’가 의미한 것

- 이전 진단은 **707장 OOF·1,154주석그룹·8,199GT**에서 수행했다. Native 5개 fold는 모두 30 epoch, YOLO는 30/30/30/30/25 epoch였다.
- 당시 최고 개발 후보의 FN 2,955개 중 **1,965개(66.50%)**는 네 geometric 뷰에 strict IoU>0.5 후보가 하나 이상 있었다.
- 최소 면적 300을 요구하면 그 수는 1,911개였다. 낮은 confidence 후보까지 포함한 여러 원시 후보를 정답과 대조한 수치다.
- 이것은 **실제 FN 1,965개 감소나 FP 감소가 아니다.** 이 후보들을 사람이 정답을 알고 골라볼 수 있었다는 진단이며, 겹침·중복·FP 비용과 실제 점수의 선택 능력을 포함하지 않는다.
- 새 품질 모델 실험은 별도의 **원래 고정 validation 91장·101주석그룹·708GT**다. 두 자료의 FN 수와 PQ를 직접 연결하지 않는다.

## 이번 91장에서도 확인한 선택 개선 여지

| 단계 | 정답 708개 중 IoU>0.5 마스크가 존재하거나 최종 매칭된 수 |
|---|---:|
| 원시 후보 전체에 존재 | 639 |
| 최소 면적 300을 충족하는 원시 후보에 존재 | **635** |
| 기존 confidence의 최종 매칭 | **453** |
| 새 품질 점수의 최종 매칭 | **383** |

- Raw/면적 단계의 값은 **후보가 하나라도 존재하는 GT 수**, 마지막 두 행은 실제 최종 예측과 매칭된 GT 수다. 앞의 수를 실현 가능한 최종 TP로 확정하지 않는다.
- 최소 면적 조건을 만족하는 후보 존재율은 635/708=약 **89.69%**다. 후보군을 더 늘리기 전에, 현재 후보를 잘 고르는 방법을 개선할 근거가 있다.
- 여러 후보가 같은 정답을 가리키거나 서로 다른 정답의 영역을 침범할 수 있다. 정답별 최고 후보를 각각 고르는 것과 하나의 비중첩 예측 집합을 만드는 것은 다르다.

## 새 모델이 복구한 것과 잃은 것

| 정답 매칭 변화 | 수 |
|---|---:|
| 두 구성 모두 맞춤 | 326 |
| 기존에 놓쳤지만 새 모델이 복구 | **57** |
| 기존에는 맞췄지만 새 모델이 놓침 | **127** |
| 두 구성 모두 놓침 | 198 |

- 기존 TP는 326+127=453, 새 TP는 326+57=383이다.
- 기존 FN 255개 중 원시 후보가 있었던 것은 186개였다. 새 모델은 그중 55개를 복구했고, 기존 raw mask의 IoU가 0.5를 넘지 않다가 clipping 후 매칭된 경우 2개를 더해 총 57개를 복구했다.
- 복구가 전혀 없었던 실험은 아니다. **복구 이득보다 기존 정답 손실이 더 컸다.**

## 기존 정답 127개를 어디에서 잃었는가

| 손실 원인 | 수 |
|---|---:|
| 모든 유효한 좋은 후보의 품질 점수가 0.15 미만 | **75** |
| 좋은 후보가 통과했으나 mask NMS에서 억제됨 | **21** |
| 선택된 좋은 후보가 픽셀 소유권 clipping 후 매칭 실패 | **31** |
| 합계 | **127** |

- 낮은 품질 점수 때문에 좋은 후보가 탈락한 것이 가장 큰 항목이다.
- 점수는 통과 여부뿐 아니라 NMS와 겹치는 픽셀의 우선순위에도 영향을 준다. 잘못된 후보가 앞서면 좋은 후보를 억제하거나 중요한 영역을 가져갈 수 있다.
- 이 분류는 기존 confidence에서 TP였던 GT가 새 구성에서 FN으로 바뀐 경우만 대상으로 한다. 후보 개수를 GT 개수처럼 더하지 않았다.

실제 예: `20110211084114Th.jpeg`의 한 정답.

- Raw 후보 index 5의 GT-IoU는 **0.6654**, 기존 confidence는 **0.4174**였다. 기존 구성에서는 정답과 매칭됐다.
- 새 품질 점수는 **0.01634**로, 주어진 threshold 0.15보다 낮아 탈락했다.
- 같은 정답에 GT-IoU **0.7177**인 다른 후보도 있었으나 품질 점수는 **0.000644**였다.
- 이 사례는 모델이 정답 후보를 생성하지 못한 경우가 아니다. **이미 있는 좋은 후보를 품질 모델이 낮게 평가한 경우**다. 원사진은 이 환경에 없어 시각적 원인까지 확정하지 않는다.

## 판별력 진단

- 원시 후보 7,172개의 저장된 target을 원본 GT에서 재계산했다. 모두 bitwise 일치했고 최대 차이는 0이었다. 입력 RLE·confidence·품질 점수는 SHA256·내용 checksum·원래 index로 연결했다.
- 최소 면적 300 후보 6,952개에서, 주석자 중 적어도 한 명과 strict IoU>0.5인 후보를 양성으로 둔 기술 통계다.

| 지표 | 기존 confidence | 새 품질 점수 |
|---|---:|---:|
| 후보 AUROC | 0.7333 | 0.6746 |
| 후보 average precision | 0.7188 | 0.6253 |
| 예상 매칭 IoU와 Spearman 상관 | 0.4419 | 0.3283 |
| 양성·음성이 모두 있는 88사진의 평균 AUROC | 0.7332 | 0.6682 |

- 새 품질 점수의 좋은 후보/나쁜 후보 구분력이 오히려 낮았다. 특정 몇 장에만 국한된 집계 현상으로 보이지 않는다.
- 정해진 gate c≥0.30, q≥0.15에서, q가 버린 c 통과 후보 663개 중 415개는 적어도 한 주석자와 매칭 가능한 좋은 후보였다. q가 새로 통과시킨 후보 1,681개 중 964개는 모든 주석자와 IoU≤0.5였다.
- 위 415·964는 **중복을 포함하는 후보 수**다. 최종 TP/FN/FP 변화량으로 해석하지 않는다.
- 여러 뷰와 후보가 같은 사진을 공유하므로 이 값은 독립 샘플 통계나 일반화 보장이 아니다. Confidence와 품질 점수는 원래 학습 목표도 다르므로 MSE만으로 동일 목적의 calibration 경쟁이라고 보지 않는다.

## PQ가 떨어진 수학적 이유

| 최종 구성 | TP-pair | FP | FN | SQ | RQ | PQ |
|---|---:|---:|---:|---:|---:|---:|
| Confidence | 453 | 260 | 255 | 0.675931 | 0.637579 | **0.430960** |
| Quality | 383 | 426 | 325 | 0.671881 | 0.504944 | **0.339262** |

`PQ = SQ × RQ = 매칭 IoU 합 / (TP + 0.5×FP + 0.5×FN)`.

- 매칭 IoU 합은 306.196927→257.330364로 약 **15.96% 감소**했다.
- 분모는 710.5→758.5로 약 **6.76% 증가**했다.
- SQ는 상대 약 0.60% 감소한 반면 RQ는 상대 약 20.80% 감소했다. 이번 하락은 평균 경계 IoU 감소보다 **정답 선택 손실과 거짓 선택 증가**가 주된 지표상 원인이다.
- 현재 평균 SQ 약 0.676이 그대로라면, FP·FN을 모두 없애도 PQ는 약 0.676이다. PQ 0.7을 목표로 하려면 정답의 수뿐 아니라 더 잘 겹치는 경계 후보를 선택하는 것도 필요하다. 이것은 SQ를 고정한 설명이며 전체 원시 후보군의 성능 상한을 계산한 결과가 아니다.

## 확인된 것과 아직 가설인 것

- **확인:** 후보군에 좋은 마스크가 많고, 새 점수의 후보 판별력이 낮으며, 좋은 후보 탈락·NMS·소유권 단계에서 실제 정답을 잃었다.
- **가설:** 원래 YOLO의 학습 사진에서 만든 후보와 unseen validation 후보의 오류 분포 차이, train 사진당 48개 선택과 validation 전체 평가의 분포 차이, 256 ROI의 세부 정보 손실 등이 학습 실패에 영향을 줬을 수 있다.
- 학습 사진 원시 후보 전체·ROI·가중치가 없으므로 위 가설 중 어떤 것이 근본 원인인지 이번 자료만으로 확정하지 않는다.
- 이번 실행은 총 20 epoch 일정의 완료본이다. Loss 감소와 validation 정체가 관찰되므로 단순히 epoch를 늘리면 해결된다고 결론내리지 않는다.

후보 생성의 성과와 이번 선택 모델의 성과를 구분한다. 현재 자료는 **선택 개선을 계속 연구할 이유**를 제공하며, 이번 독립 품질 점수 모델은 그 역할을 충족하지 못했다. 이후 실험의 방향을 바꾸거나 실행하기 전에 이 진단을 기준으로 삼는다.
