# DETR 60→80에폭 결과: bbox와 best84 연결 가능성 검토

검토일: 2026-11-02, America/Chicago. 입력은 `detr_longrun_c27c4813ec0a_part01.zip`이다. 이번 검토에서는 검출기 자체의 개선과 고정 ROI U-Net을 거친 최종 PQ를 구분했다.

**판단: PQ 최고 모델은 70에폭이지만, bbox를 best84에 전달하는 다음 실험에는 80에폭도 보존해야 한다.** bbox 성능은 조금 개선됐으나 오검출까지 동시에 안정된 상태는 아니다. 기존 best84의 저장 마스크를 단순히 추가·제거하는 방식으로는 기존 전체 기준선을 넘지 못했다. bbox를 이용한 1024 타일 구성은 별도로 검증할 가치가 있다.

## 학습과 파일 확인

- ZIP은 전체 1개 중 1개이며 누락이 없다. 내용물 231개 파일의 크기·SHA256, ZIP CRC, 배포 코드 11개의 해시를 확인했다. 업로드된 코드를 실행하지 않았다.
- 고정 검증셋은 물리사진 91장, annotator별 101그룹, GT 708개다. 동일 사진의 다른 annotator는 별도 평가하며, 불확실성 계산에서는 물리사진 단위로 묶었다.
- 학습은 기존 60에폭에서 20에폭을 추가해 **누적 80에폭에서 정상 조기 종료**됐다. 150은 누적 최대치였다.
- 매 에폭 같은 confidence 0.6/0.8/0.9 중 최고 마스크 PQ를 보았으며, 70에폭 이후 10에폭 동안 PQ 0.001 이상의 개선이 없어 종료됐다. 종료 횟수와 저장 기록이 일치한다.
- A100-SXM4-40GB, DETR 입력 1280, batch 2·누적 2, BF16 본체·FP32 bbox 헤드였다. ROI ResNet34 U-Net30은 고정했다.
- 추가 학습의 optimizer 업데이트는 기록상 5,280회이고 AMP 건너뜀이 없다. 마지막 5에폭 평균 loss는 1.04211로 처음 5에폭 평균 1.06871보다 2.49% 낮다. bbox loss는 같은 비교에서 3.80% 낮다.
- 가중치 자체는 업로드 ZIP에 포함되지 않았다. 파일에 기재된 Drive 경로와 체크포인트 해시는 확인했지만, 원격 Drive 가중치 파일 바이트를 직접 재검증한 것은 아니다.

## bbox 성능

아래 AP는 저장된 confidence≥0.05 bbox로 계산한 COCO 방식 진단값이다. 공식 대회 마스크 PQ가 아니며, 더 낮은 confidence 후보는 없어서 완전한 원시 모델 AP로 단정하지 않는다. AP를 새로 계산할 수 있는 원시 예측은 60·70·80에폭이다. 중간 에폭은 숫자 보고서만 남았다.

| 지표 | 60에폭 | 70에폭 | 80에폭 |
|---|---:|---:|---:|
| bbox AP50:95 | 0.240833 | 0.243515 | **0.249899** |
| bbox AP50 | 0.550816 | 0.551279 | **0.565663** |
| bbox AP75 | 0.166606 | 0.169729 | **0.177529** |
| IoU>0.5 검출, confidence 0.05 | 581/708 | 569/708 | **584/708** |
| IoU>0.75 검출, confidence 0.05 | 256/708 | 261/708 | **266/708** |
| 작은 객체 IoU>0.5 검출, confidence 0.05 | 116/180 | 114/180 | **119/180** |
| IoU>0.5 TP, confidence 0.8 | 443 | 462 | **472** |
| FP, confidence 0.8 | 416 | 421 | 463 |

- 작은 객체는 GT 마스크 면적 670px 미만인 180개이며 COCO의 small 정의와 다르다.
- 60→80에폭에서 confidence 0.8의 TP는 29개, FP는 47개 증가했다. 물리사진 paired bootstrap 95% 구간은 각각 [14,44], [21,73]이다.
- 80에폭의 낮은 confidence bbox 재현율은 82.49%, 작은 객체는 66.11%다. 아직 bbox 정답 검출률 90%에 도달한 것은 아니다.
- 같은 FP 예산으로 비교하면 80이 모든 조건에서 우월하지 않다. FP≤400에서는 TP가 441→455→456이지만, FP≤300에서는 409→429→414로 70에폭이 가장 좋다. 이 예산별 값은 개발셋 점수곡선에서 얻은 서술적 도달 가능치이며 배포 threshold 확정값이 아니다.
- 전체 60~80에폭 숫자 기록에서도 confidence 0.05와 0.8의 IoU>0.5 TP는 80에폭이 최고다. 반면 confidence 0.05의 IoU>0.75 TP 최고는 67·72에폭의 269개로, 80에폭 266개보다 높다. 모든 위치 정확도 지표가 단조롭게 개선된 것은 아니다.
- 60→80의 AP50:95 상승은 +0.009066이다. 조건부 사진 묶음 bootstrap 95% 구간은 [+0.000226,+0.017325]지만, 70→80의 구간은 0을 포함한다. 반복 개발셋의 작은 개선이며 독립 리더보드 개선을 입증하지 않는다.

## 고정 ROI U-Net PQ와 후보 손실

| 동일 confidence 0.8 | 60에폭 | 70에폭 | 80에폭 |
|---|---:|---:|---:|
| 최종 PQ | 0.393816 | 0.402423 | 0.396818 |
| TP | 435 | 449 | 450 |
| FP | 336 | 341 | 362 |
| FN | 273 | 259 | 258 |
| 원시 후보에 IoU>0.5 마스크가 존재하는 GT | 454 | 467 | 479 |

- **80에폭은 70에폭보다 올바른 원시 마스크 후보가 많지만 최종 PQ는 낮다.** FP 증가와 중복 제거·픽셀 소유권 배분 과정의 손실이 함께 작용한다.
- 원시 후보 존재는 GT로 사후 검사한 진단값이다. 정답을 실제로 골라낼 수 있는 최종 재현율과 같지 않다.
- 각 에폭에서 confidence를 따로 선택한 최고 PQ는 60에폭 0.393816@0.8, 70에폭 0.407451@0.9, 80에폭 0.405682@0.9다. 70에폭 최고점은 60에폭 최고점보다 TP가 50개 적고 FP가 153개 적으므로, 이 비교만으로 FN 개선을 주장해서는 안 된다.
- 70에폭 최고 PQ 상승 +0.013635의 사진 단위 bootstrap 95% 구간은 [-0.002232,+0.028310]이다. 같은 개발셋에서 에폭·threshold를 선택한 영향을 보정한 독립 평가가 아니다.
- 최종 CSV 9개와 21개 에폭의 confidence별 점수 63개를 검산했다. 새 60에폭 기준선과 이전 CSV는 TP·FP·FN이 동일하며 ROI 배치 변경에 따른 PQ 차이는 최대 0.0000019였다.
- 현재 ZIP에는 confidence≥0.6의 ROI 마스크만 있다. 더 낮은 confidence의 bbox는 있지만 그 bbox에서 생성할 ROI 마스크를 새 추론 없이 평가할 수는 없다.

## best84용 1024 타일 구성

GT를 사용하지 않고 각 예측 bbox를 가로·세로 1.5배 확장한 뒤, 그 영역을 덮는 기존 1024 타일을 선택했다. 시작 좌표는 각 축 [0,768,1024]이며 중복 타일을 합쳤다. 원본 픽셀 크기를 유지하고 bbox를 1024로 확대하지 않았다.

아래 표는 **기본 뷰 한 개의 기하학적 포함률**이다. 포함 성공은 GT 마스크 픽셀의 95% 이상이 선택 타일의 합집합 안에 있다는 뜻이며, 실제 검출 성공이나 분할 성공이 아니다.

| 설정 | 이미지당 평균 타일 수 | GT 포함 성공 | 평균 이미지 면적 포함률 |
|---|---:|---:|---:|
| 기존 전체 9타일 | 9.00 | 708/708 | 100% |
| DETR70, confidence 0.8 | 4.78 | 694/708 | 75.1% |
| DETR80, confidence 0.8 | 4.90 | **700/708** | 76.4% |
| DETR80, confidence 0.6 | 5.49 | **706/708** | 80.6% |

- 80에폭 confidence 0.8에서 같은 사진별 타일 수로 9타일 중 균등하게 선택하는 대조군의 기대 포함 수는 622.84/708개였다. DETR 위치 정보는 같은 타일 예산에서도 유용했다. 대조군은 가능한 모든 동일 개수 타일 조합의 정확한 평균이며 GT는 점수 계산에만 사용했다.
- 다만 700/708 또는 706/708은 **넓은 입력 영역의 포함률**이다. 82.49%인 직접 bbox 검출 재현율과 혼동하면 안 된다.
- 80에폭 confidence 0.6에서 하나의 타일 안에 GT의 95% 이상이 들어가는 객체는 699개다. 타일 합집합의 706개와 구분해야 하며, 여러 타일에 걸친 객체는 stitching 품질이 중요하다.
- bbox마다 별도의 중심 타일을 만들면 중복이 늘었다. 80에폭에서 confidence 0.8은 평균 9.25타일, 0.6은 12.79타일로, 기존 9타일보다 추론량이 늘 수도 있다.
- 실제 best84는 기본·좌우·상하·양방향 반전의 4뷰를 사용한다. 반전 후 타일의 원본 좌표도 달라지므로, 각 뷰에서 bbox를 함께 변환해 타일을 선택하고 예측을 역변환해야 한다. 위 표를 실제 전체 4뷰 추론 성능으로 읽으면 안 된다.
- 일부 타일을 제외하면 주변 문맥과 Hann blending 가중치가 바뀐다. 기존 전체 타일의 합성 마스크만으로 새 타일 선택의 예측을 정확히 재현할 수는 없다. 실제 best84 재추론 또는 타일별 확률 출력이 필요하다.

4뷰 좌표를 정확히 반영한 추가 기하학 진단은 다음과 같다. 실제 신경망 추론 시간이나 PQ를 측정한 표가 아니다.

| 4뷰 구성 | 이미지당 타일 forward 수 | GT 95% 포함 | 평균 원본 면적 포함 | 동일 뷰별 예산 무작위 선택의 기대 포함 |
|---|---:|---:|---:|---:|
| 기존 전체 타일 | 36.00 | 708 | 100% | 708 |
| DETR70, confidence 0.8 | 19.09 | 701 | 84.2% | 702.1 |
| DETR80, confidence 0.8 | 19.59 | 703 | 85.4% | 702.5 |
| DETR80, confidence 0.6 | 21.70 | 706 | 88.0% | 706.3 |

- 4뷰 대조군은 뷰별로 같은 타일 수를 무작위 선택하는 32회 재현 가능한 샘플이다. 대조군의 면적 포함률은 각각 94.7%, 95.0%, 97.2%였다.
- **4뷰에서는 같은 타일 예산의 무작위 선택도 대부분의 GT를 포함한다.** 기본 뷰 한 개에서의 우위를 4뷰 전체로 확대해 해석하지 않는다. 확인된 것은 대상 처리 영역을 더 좁히면서 GT를 많이 포함할 수 있는 기하학적 가능성이다.
- 36→21.70이라는 native 분기 forward 감소에는 DETR 실행 비용이나 기존 전체 파이프라인을 보완분기로 유지할 비용이 포함되지 않는다. 전체 처리 시간 절감이 입증된 것은 아니다.
- 극단 경계를 포함한 104개 bbox에서 타일 크기·확장 영역 포함·4뷰 좌표 역변환을 검사했다. 세부 결과는 `tiles/tta_geometry_results.json`에 있다.

## 저장된 best84 마스크와 실제 결합한 결과

새 bbox를 이용해 기존 best84 후보를 추가하는 8개 규칙과, bbox 지지가 없는 기존 마스크를 제거하는 4개 진단을 수행했다. ResNet ROI 마스크와 GT 기반 특징은 후보 생성에 사용하지 않았다.

| 구성 | PQ | FP | FN |
|---|---:|---:|---:|
| 기존 전체 YOLO+best84 기준선 | **0.471930** | 204 | 221 |
| DETR70 bbox로 best84 후보 추가, 가장 나은 규칙 | 0.471400 | 211 | 218 |
| DETR80 bbox로 best84 후보 추가, 가장 나은 규칙 | 0.471098 | 210 | 219 |

- 추가 규칙에서는 기존 마스크를 byte 단위로 보존했다. 가장 나은 규칙도 GT 3개 복구·손실 0개에 FP 7개 증가로 PQ가 낮아졌다.
- bbox 지지가 없는 기존 마스크를 일괄 제거하면 GT 36~62개를 잃고 PQ가 0.4551~0.4633으로 낮아졌다. 이 방식은 채택하지 않는다.
- 관측 연월을 묶어 규칙 선택과 평가를 분리한 보조 분석에서도 기준선을 넘지 못했다. 이 분석 역시 반복 사용한 고정 validation이며 새 모델의 5-fold OOF 결과가 아니다.
- 이것은 **저장된 마스크 선택·추가 실험**이다. bbox 주변에서 best84를 새로 추론하는 방법까지 실패했다고 해석하지 않는다.

## 다음 단계와 보존할 가중치

1. 기존 제출 파이프라인은 유지한다. 새 경로가 이를 대체할 만큼 좋아졌다는 증거는 아직 없다.
2. 아래 70·80에폭 가중치를 모두 보존한다. PQ가 낮다는 이유로 80에폭을 버리지 않는다.
3. 다음 GPU 실험은 추가 학습보다 **같은 bbox → best84 재추론·기존 전후처리**의 비교를 우선한다. 80에폭 confidence 0.6/0.8을 재현율 후보로, 70에폭을 오검출 억제 비교 후보로 둔다. 넓은 threshold 탐색은 피한다.
4. 전체 이미지 limb 전처리를 먼저 적용하고, 원본 1024 스케일·4뷰 역변환·타일 결합을 유지한다. 기존 전체 파이프라인, 새 타일 기반 best84 경로, 동일 bbox의 ResNet34 ROI 경로를 구분해 평가한다.
5. GT 입력 포함률, 최종 GT 복구·손실, FP, SQ·RQ·PQ, 추론량을 함께 기록한다. 포함률만으로 SQ가 보장됐다고 판단하지 않는다.
6. 그 비교 후 DETR을 더 학습한다면 bbox AP·고정 FP 수준의 재현율을 checkpoint 선택 기준에 포함하는 별도 실험으로 만든다. 완료된 PQ 조기 종료 상태를 임의로 초기화하거나 기존 출력 폴더에 다른 기준을 덮어쓰지 않는다.
