# 후보 조건과 명암 단서 재검토

## 현재 판단

- 현재 후보 **생성** 단계에는 낮은 confidence의 마스크까지 상당수 존재한다. 큰 손실은 이를 최종 출력으로 **채택**하는 조건에서 발생한다.
- 실제로 조건을 완화하면 정답을 더 찾지만 오검출도 더 많이 증가했다. 따라서 기존 기준선은 유지하며, 완화된 후보를 구별하는 단서를 검증한다.
- 태양 원반 안의 Hα 필라멘트는 주변 배경에 비해 어두운 흡수 구조로 보인다. 주변 대비는 타당한 단서지만 흑점·미세한 표면 구조·조명 차이도 어두움을 만들 수 있다. 밝기만으로 annotation의 객체 범위와 IoU>0.5를 보장할 수는 없다.
- 가까운 배경 대비, 구조의 폭과 길이, 길이를 따른 변화, 주변 문맥을 함께 다루는 방향으로 검증한다. 원반 바깥의 밝은 홍염까지 동일한 어두움 규칙으로 처리한다는 의미는 아니다.

## 완료한 임계값 완화 실험

이전 연결 종료로 점수 확인이 남았던 두 CSV를 그대로 재평가했다. 새로 임계값을 탐색하지 않았다. 기존 고정 값은 기준선 PQ/2인0.2361367837이며, 다른 후보 추가 조건은 유지했다.

| 조건 | validation PQ | TP | FP | FN |
|---|---:|---:|---:|---:|
| 기존 전체 YOLO+best84 | 0.472274 | 488 | 205 | 220 |
| 기존 품질모델, 낮춘 임계값 | 0.465021 | 491 | 232 | 217 |
| 추가30epoch 품질모델, 낮춘 임계값 | 0.463270 | 494 | 243 | 214 |

- 새 모델에서 FN6개를 줄였지만 FP38개가 증가했다. 두 규칙 모두 미채택이다.
- 원래626개 마스크의 ID와 픽셀을 유지했고 새 출력의 겹침은0이었다.
- 낮춘 값은 추가 마스크의 예상 IoU 기여와 PQ 분모 증가의 관계에서 도출한 진단값이다. 모델 점수가 정확하게 보정되지 않거나 후보 간 상호작용이 있으면 성능 개선을 보장하지 않는다.

## 이미 사용하거나 시험한 밝기 처리

- 현재 파이프라인은 태양 가장자리의 방사형 밝기 보정과 여러 전처리 뷰를 포함한다. CLAHE, percentile, unsharp, Gaussian, bilateral, blackhat 후보를 조건부로 사용한다.
- 과거 초기 fixed91 YOLO 분기에서는 조건부 전처리 후보 추가로 PQ0.457152→0.459118, FN241→229가 관측됐다. 이는 현재 전체 YOLO+best84 기준선0.472274와 다른 단계의 기록이다.
- 평균 어두움·주변 대비에 따른 추가 규칙48개는 이전 기준선0.460759를 넘지 못했다.
- OOF707의 어두움·ridge·방향 특징 규칙20개도 당시 최고0.4367525를 넘지 못했다.
- 밝기·주변 대비·gradient·texture를 포함하는102개 특징의 CPU 선택기 역시 해당 실험의 기준선0.430960에서 일관된 개선을 보이지 않았다.
- 따라서 이번에는 같은 평균 밝기 문턱을 반복하기보다 공간적으로 어디가 어두운지 측정하는 방법을 추가했다. 과거 결과는 `history_audit.ko.md`에 서로 다른 기준선별로 구분했다.

## 보유 밝기 특징의 구별력 확인

원본 JPEG에서 수집했던 밝기 특징과 기존 validation7172개 후보를 정확한 RLE·순서로 연결했다. 새 학습·임계값 탐색·예측 CSV 생성 없이 미리 정한3개 특징의 순위만 비교했다. 특징은 기존 수집값이며 이번 서버에서 원본 JPEG 전체를 다시 읽어 계산한 것은 아니다.

| 지표 | 전체7172후보 AUROC | Q50의 품질 외 조건을 통과한406후보 AUROC |
|---|---:|---:|
| 영상 전체 기준으로 정규화한 내부 어두움 | 0.5547 | 0.5627 |
| 가까운 배경 띠와의 명암 차이 | 0.6185 | 0.5729 |
| 세 스케일의 배경 대비 중앙값 | 0.6184 | 0.5742 |
| 원래 YOLO confidence | 0.7355 | 0.5040 |

- AUROC0.5는 무작위 순위 수준이며1에 가까울수록 정답 후보를 높은 순위로 구별한다. 이 값은 PQ가 아니다.
- 어려운 잔여 후보에서는 주변 대비에 약한 정보가 있다. 그러나0.57 정도의 구별력만으로 안전하게 후보를 추가할 수 있다고 판단하지 않는다.
- 같은 사진·객체의 여러 마스크가 포함된 후보 단위 기술통계다. 독립 표본7172개의 통계 검정이나 새로운 데이터에서의 일반화 성능으로 해석하지 않는다.

## 새로 고정한 공간 명암 실험

- 후보 마스크의 중심선을 추출하고, 중심선 각 지점 주변에서 진행 방향을 계산한다.
- 진행 방향에 수직으로 중심과 양쪽 배경을 샘플링한다. 양쪽 중 한쪽만 어두워지는 완만한 조명 경계에 반응하지 않도록 **양쪽 모두 중심보다 밝아야** 높은 점수를 준다.
- 배경의 국소 변동으로 명암 차이를 정규화하고 중심선 전체의70% 이상에서 조건을 만족하는지 계산한다.
- 이70%는 중심선을 따라 조건이 성립하는 비율이다. 그래프상으로 한 줄이 연속 연결되는 길이까지 측정한 것은 아니다.
- 후보 수집 조건은 confidence≥0.05, 면적≥150, 기존 마스크와 낮은 겹침, 최대5% 겹침 제거다. 기존 품질CNN 점수와 두 뷰 합의는 요구하지 않는다.
- 비교는3개로 고정했다: 같은 가용 후보를 모두 추가하는 대조군 / 양측 명암z≥1을 요구 / z≥2를 요구. 순위는 모두 confidence 기준이며 기존 마스크는 보존한다.
- 사용 영상은 보유한91장의 원래2048좌표계 limb 보정 PNG 타일이다. 원본 전체 영상이 아니므로 후보와 양쪽 배경의 필요한 픽셀이 있는지 검사했다. 픽셀이 없는 부분을 검은색으로 해석하지 않는다.
- 어두운 곡선+완만한 밝기 경사, 밝기 경사만 있는 영상, 픽셀 누락, 반전·평행 이동 사례로 구현을 점검했다. 모든 예측을 고정한 후 GT로 평가한다.

## 공간 명암 실험 결과

| 방법 | validation PQ | TP | FP | FN |
|---|---:|---:|---:|---:|
| 기존 전체 파이프라인 | 0.472274 | 488 | 205 | 220 |
| 공통 가용 후보를 넓게 추가 | 0.421758 | 524 | 450 | 184 |
| 양측 명암z≥1, 중심선70% 지지 | 0.426048 | 523 | 430 | 185 |
| 양측 명암z≥2, 중심선70% 지지 | 0.430891 | 516 | 398 | 192 |

- 세 실험 모두 기존 전체 파이프라인보다 낮아 미채택이다. 약한 후보 추가 대조군에 비해서는 강한 명암 조건이 FP52개를 줄였지만 TP8개도 줄였다.
- 기존 기준선과 비교하면 강한 명암 조건도 FN28개 감소에 FP193개 증가였다. 밝기 단서가 충분히 높은 정밀도로 누락 후보를 골라내지 못했다.
- 새 기법에 적절한 픽셀·형태 조건을 만족한 후보는1098개였다. 필요한 마스크 픽셀이 없는454개, 배경 프로필 픽셀이 부족한8개, 국소 방향·중심선 조건이 부족한8개는 공통으로 제외했다. 대상 후보를 먼저 고른 과거 타일 캐시이므로 픽셀 가용성이 무작위라는 가정은 하지 않는다.
- 이1098개 안에서 어떤 annotator의 GT와라도 IoU>0.5인 후보는180개였다. 후보 단위 AUROC는 중심선 대비의30%분위수0.4948, 양측 대비 중앙값0.5229, confidence0.5441로 모두 약했다. 앞의406개 특징 진단과 후보군·영상 전처리가 달라 지표를 직접 일대일 비교하지 않는다.
- 원래626개 마스크의 ID·RLE를 보존했고, 최종3개 CSV 모두 겹침0을 별도 확인했다. 생산 코드와 제출 파일은 바꾸지 않았다.
- 중심선 국소 방향·양측 명암·누락 픽셀 처리에 대한 추가 독립 검사9개도 통과했다. 검증 통과는 구현 의도와 일치한다는 뜻이며 성능 개선의 증거는 아니다.
- 이 결과는 어두운 구조의 존재만으로 객체의 폭·경계·분리 단위를 구별하기 어렵다는 점과 일치한다. 이어지는 명암 가설은 단순 어두움 문턱보다 **수직 밝기 프로필에서 관측되는 폭·경계와 후보 마스크의 범위가 얼마나 맞는가**를 비교하는 것이다. 이 후속 가설의 성능은 아직 측정하지 않았다.

세부 수치와 고정 설정은 `bilateral/result.json`, `bilateral/protocol.json`, 독립 검토는 `bilateral/independent_review.json`에 보관했다.

## 평가 범위

- 실제 PQ는 고정 validation91장의 정답으로 계산한다. 반복 사용한 개발 분할이며 독립 OOF·새 리더보드 결과가 아니다.
- 새 공간 명암 특징은 test에서 수집하지 않았으므로, 이 방법의 test 참조216/102 대응은 미측정이다. 이전 test318개 후보 경로 진단을 새 명암 방법의 성적으로 대신 쓰지 않는다.
- 새로운 GPU 학습이나 리더보드 제출은 하지 않았다. 자체 LB0.39·공개 예측을 섞은 혼합 제출0.45·공개 원본0.55를 구분한다.
