# FN·FP 개선 실험 — 2026-11-02

## 점수 기준과 이번 실험의 범위

- Public LB 0.55: 공개 RLE 제출을 사용자가 직접 제출해 확인한 점수. 두 개의 사각형 fallback을 제거해도 표시 점수는 0.55였다.
- 자체 파이프라인의 확인된 public LB: 0.39. 고정 검증 PQ 0.472593은 이와 다른 지표이며 동일시할 수 없다.
- 이번 OOF 기준선: 707장, 1,154개 주석 그룹, GT 8,199개, PQ 0.436752508.
- 이번 fixed91 native/ROI 기준선: 같은 T4 실행에서 PQ 0.472273567. 과거 A100 결과와 섞지 않았다.
- 후보 교체 학습의 fixed91 기준선은 다른 YOLO 후보 corpus의 PQ 0.430959785다. 각 실험은 해당 기준선 대비 변화로 평가해야 한다.
- 공개 제출의 RLE는 test **예측**이며 정답은 아니다. RLE 두 벌과 집계 점수 0.55·0.39만으로 숨겨진 정답 마스크를 복원할 수 없다. 이번에는 실제 정답이 있는 검증 자료로 개선 여부를 측정했다.
- 추가 신경망 학습이나 GPU 추론 없이 저장된 후보를 사용했다. 후보 교체기와 추가 선택기는 train616의 특징으로 CPU에서 학습했다.

### 공개 0.55 RLE에서 가져온 단서

- 앞선 동일 176장 비교에서 공개 예측은 1,338개, 자체 예측은 1,341개로 총 객체 수가 거의 같았다. 따라서 객체를 많이 추가하는 것만으로 점수 차이를 설명할 수 없다.
- 공개 예측의 중앙 면적은 1,290px, 자체 예측은 1,221px였다. 서로 IoU>0.5로 대응한 924쌍에서 자체/공개 면적 비율 중앙값은 약 0.911이었다.
- 이 차이를 정답으로 간주하지 않고, '일부 마스크의 잘린 부분을 복원할 여지가 있는가'라는 가설로 옮겨 OOF에서 검증했다.
- 공개 예측에 작은 분리 조각과 구멍이 더 있다는 관찰도 형태 정리 가설의 출발점이었다. 실제 검증에서는 그 효과가 매우 작았다. 공개 예측과 더 닮았다는 이유만으로 개선이라고 판정하지 않았다.

## 1. 선택된 마스크의 잘린 부분 복원 — 개선 후보

- 기존 4,999개 인스턴스와 모든 원래 픽셀을 유지한다.
- 한 객체와 연결된 기하 뷰 후보 중 최소 2개가 동시에 지지하고 native 모델도 foreground로 판단한 누락 픽셀만 추가한다.
- 기존 객체와 연결되어야 하며, 면적 증가는 최대 25%다. 다른 객체를 침범하거나 추가 결과끼리 충돌하면 되돌린다.
- GT를 보기 전에 규칙 2개와 모든 OOF 예측을 고정했다. 실제 적용에는 원시 기하 뷰 마스크와 native 확률 임계값별 마스크가 필요하다.

- 별도 evaluator와 독립 코드 검토로 점수, GT 전이, ID·개수·원래 픽셀 보존, 비중첩을 확인했다.
- **OOF 개선 후보로 보존한다. public LB 개선 또는 최종 배포 채택을 의미하지 않는다.** 공개 0.55 CSV에는 원시 추론 뷰가 없어 이 규칙을 그대로 실행할 수 없다.

- 기존 T4 기준선 마스크를 그대로 두고, native와 ROI 모델이 서로를 최고 IoU 후보로 선택할 때만 새 객체를 추가했다.
- 교차 모델 IoU 0.50 / 0.65와 출력 마스크 native / ROI의 총 4개 조합을 사전에 고정했다.
- 검증 결과는 PQ **0.471214–0.472105**로 모두 기준선 **0.472274**보다 낮았다.

- 예: native/IoU0.50은 TP 5개와 FP 12개를 추가했다. IoU 합은 3.407 증가했지만 기존 PQ 유지에 필요한 증가는 4.014였다.
- 독립 검증에서 GT 접근을 차단한 채 예측을 재생성했고 출력 SHA가 전부 일치했다. 네 규칙 모두 ΔPQ의 95% 구간에 0이 포함된다.

## 6. 기대 매칭 IoU를 학습한 새 후보 추가

- 기존 confidence 0.30 기준선 마스크는 모두 보존하고, 아직 선택되지 않은 후보의 **추가 매칭 IoU 기대값**을 train616만으로 학습했다. 전체 후보의 순서를 다시 매기는 방식과 다르다.
- 후보는 기존 마스크와 최대 IoU ≤0.10, 점유 영역과 겹침 ≤25%, 잘라낸 뒤 면적 ≥300px 조건을 통과해야 한다. 추가 후보끼리 겹치면 NMS와 소량 잘라내기를 적용하되, 기존 마스크는 변경하지 않는다.
- 594/616장에 학습 가능한 후보가 있었으며 총 12,079개, 양의 target 2,955개·0 target 9,124개였다. 114개 특징을 입력으로 고정 HGB 하나를 학습했다. 실행 시간은 약 6.66분이다.
- 이득 조건 0.25 / 0.35를 사전에 고정했다. 두 예측을 저장한 뒤 검증 GT로 평가했으며 임계값 재탐색은 하지 않았다.

### 점수를 확인한 뒤 수행한 후보 존재 진단

- 기준선 FN 255개 중 **182개**에는 raw 후보 풀 안에 strict IoU>0.5 마스크가 있었다. **73개**는 raw 후보 풀에도 없었다.
- 보수적인 추가 조건과 잘라내기를 통과한 풀에는 이 중 **77개**가 남았다. 나머지 **105개**의 raw 기회는 해당 제한 조건을 거친 풀에서는 찾을 수 없었다.
- 통과 풀은 검증 사진 87/91장, 후보 1,569개였다. 그중 301개는 적어도 한 주석자에 대해 매칭되는 후보였으나, 중복 후보가 있어 이를 GT 개수로 해석하지 않는다.
- 실제 0.25 조건이 복구한 것은 77개 중 **5개**다. 생성된 후보가 있어도 안정적으로 고르는 문제는 여전히 남았다.
- 이 진단은 GT를 사용한 '존재 여부' 분석이다. 77개를 전부 동시에 복구할 수 있다거나 그만큼 PQ가 오른다는 보장은 아니다. 이 결과로 임계값이나 예측을 수정하지 않았다.

## 후속 연구에 남긴 단서

- 현재 긍정 신호는 국소적인 마스크 복원과 쌍별 교체에 있다. 기존 예측을 모두 다시 정렬하는 것보다 변경 범위를 제한한 이번 설정에서 손실을 줄였다. 모든 데이터에 통하는 결론은 아니다.
- 추가 가능한 정답 후보 77개 중 실제 복구는 5개였다. 단순 confidence 완화보다, 추가될 객체가 정답인지 구분하는 특징과 선택 목적함수 개선을 우선 연구할 근거다.
- 이번 추가기는 기존 객체와 IoU≤0.10, 교체기는 IoU≥0.25 대안만 다뤘다. 이 두 신규 실험 사이의 중간 겹침 구간은 다루지 않았다. 후속 실험에서는 기존의 잘 맞힌 객체를 보호하면서 겹침·분할을 처리하는 국소 편집을 별도 규칙으로 검증할 수 있다.
- Public 0.55 RLE만으로 새 선택기에 필요한 픽셀 특징·추론 뷰를 얻을 수 없다. 실제 test 후보를 만들고 같은 규칙을 적용한 결과가 있어야 public 성능을 확인할 수 있다. 현재는 소규모 개발 개선 후보를 보존하는 단계다.

## 이번 결과의 사용 범위

- 검증 CSV는 Kaggle test 제출 파일이 아니다. 이번 실험으로 public 0.55를 갱신했다고 주장하지 않는다.
- OOF의 native 학습량은 모든 fold 30epoch, YOLO는 30/30/30/30/25epoch다. 균일한 학습량의 최종 성능 추정이 아니며, 이미 여러 실험에 반복 사용됐다.
- 고정 분할 학습은 train616만 사용하고 validation91에서 점수를 확인했다. 모델 선택과 후처리 연구에 같은 validation을 반복 사용했으므로 독립 평가로 해석하지 않는다.
- FN 감소 여부만 보지 않고 FP, 매칭 IoU 합, 기존 TP 손실을 함께 확인했다. 이번 결과에서 효과 없는 규칙은 기존 기준선에 합치지 않았다.
