# 원영상 픽셀 품질 특징 실험 V4

## 결론

- **현재 최고 개발 후보 PQ0.436752508을 유지했다.** 이번20개 설정은 모두 미채택했다.
- 밝기·ridge·방향 일관성을 단순 gate나 순위로 쓰는 것만으로는 FN 복구에 필요한 FP 비용을 충분히 낮추지 못했다.
- FP 제거 V5는 고정 기준보다 조금 높았지만 기존 P1 제거와 현재 최고 후보보다 낮았다. 이를 새 최고 성능으로 보고하지 않는다.
- 이번 실패는 이20개 고정 규칙의 결과다. 특징 자체가 다른 품질 모델이나 경계 판별에 쓸모없다는 증거는 아니다.

## 데이터와 검증 범위

- 물리 이미지 **707장·주석자별1,154그룹·정답8,199개**의 같은 OOF를 사용했다.
- Native는 모든fold30epoch, YOLO는 **30/30/30/30/25epoch**다. 같은30epoch 예산의5fold로 표시하지 않는다.
- 고정 기준은 **PQ0.431873883 / TP5187 / FP2919 / FN3012**다.
- 유지한 최고 후보는 **PQ0.436752508 / TP5244 / FP2891 / FN2955**다.
- 평가 방식은 strict IoU>0.5의 모든 qualifying pair를 global 누적하는 기존 공식 의미를 유지했다. Fold PQ의 단순 평균이 아니다.
- 같은 OOF에서 규칙을 반복 비교하므로 독립적인 최종 검증이나 새 public LB 결과로 해석하지 않는다.

## 특징 수집 자료 감사

- ZIP2개·파일5개의 SHA-256과 CRC를 검증했다. CSV/JSONL의 모든 행과 수치 유효성, 이미지별 record SHA 재구성, RLE hash·좌표·면적·novelty·confidence·native 지지와 부모 이미지/모델 출처가 일치했다.
- 수집은 **707장 모두 완료**됐다. 특징 행이 있는 사진은706장이고, `20200105073250Uh.jpeg`는 대상 마스크가0개여서 행이 없다. 이사진도 평가707장에 그대로 포함했다.
- 특징은 **34,725행 = 기준 마스크4,978개 + novel raw 후보29,747개**다. 후보 위치는 예측으로 정했으며 정답으로 고르지 않았다.
- 원본 JPEG는 이환경에 없으므로 실제 픽셀에서 scalar 특징을 독립적으로 다시 계산하지 못했다. 여기서 확인한 것은 특징 수치와 실행소스·원본/예측 출처의 연결 및 파일 무결성이다.
- 업로드 Python은 데이터로 읽었고 실행하지 않았다. 이번 평가에서는 **새 모델 학습·새 신경망 추론을 하지 않았다.**

## 실제 비교한 설정 수

- 후보 복구6개 + 현재 최고 후보로의 사전 지정 전이2개: **8개**.
- FP 제거·보호 규칙: **6개**.
- 후보 순위/군집 대표 선택4개 + 현재 최고 후보로의 전이2개: **6개**.
- 합계 **20개 설정**이다. 기준 유지·기존Y1·기존P1·최고 후보의 대조군은 별도다.
- 각 실험 묶음에서 전체 CSV를 생성한 뒤 GT로 채점했다. 대조군을 포함한 CSV는140개다. 동일한 출력을 내는 설정도 있으므로 고유 알고리즘 수나 독립 검증140회로 해석하지 않는다.
- 새20개 설정의 저장 CSV를 별도 코드로 다시 읽어 PQ·SQ·RQ·TP·FP·FN·IoU합을 모두 재계산했고, 각 report와1e-12 허용 오차 안에서 일치했다. 마스크 비중첩과 주석그룹 중복 없음도 확인했다.

## 후보 복구:6개 gate와2개 전이

- 어두움만, 어두움+ridge+방향, 강한 선 구조, 낮은confidence+강한 선 구조, 곡선용 anisotropy, 작은 객체용 선 구조를 고정 규칙으로 비교했다.
- 마스크 지지 family·confidence·novelty·면적·픽셀 소유권을 함께 제한했다. 기존 마스크는 모두 보존했다.
- Darkness-only와 curve-anisotropy는 기존Y1과 출력이 같았다. 해당 pool의 거짓 추가 후보를 더 걸러내지 못했다.
- 다음 표의 변화는 각 행에 표시한 기준에 대한 값이다.

| 대표 규칙 | 비교 기준 | PQ | ΔFP | ΔFN |
|---|---|---:|---:|---:|
| 작은 객체·강한 선 구조 | 고정 기준 | 0.431792215 | +69 | −28 |
| 강한 선 구조 | 고정 기준 | 0.430388797 | +221 | −79 |
| 낮은confidence·강한 선 구조 | 고정 기준 | 0.426378960 | +599 | −187 |
| 최고 후보+dark/ridge | 현재 최고 | 0.434936266 | +150 | −41 |
| 최고 후보+낮은confidence | 현재 최고 | 0.431140414 | +501 | −143 |

- 작은 객체 규칙의 조건부 paired bootstrap95% ΔPQ 구간은 **[−0.000864,+0.000791]**다.
- 모든 복구·전이 규칙에서 원래 비교 기준의 GT 매칭 손실은0이다. 그래도 추가 FP 때문에 PQ가 낮아질 수 있었다.
- 전이된 규칙은 기존 최고가 만든 새 마스크에 원본 index의 특징을 억지로 붙이지 않았다. 같은 raw 후보에 원래 snapshot에서 수집한 특징을 고정하고 새 기준과 novelty·소유권을 다시 검사했다.

## FP 제거:6개 규칙

- 어둡지 않은 후보, isotropic blob, 주변 ridge가 강한 후보, P1 제거에 광학 근거 추가, P1에서 coherent line 보호, P1에서 darkness 또는 line 보호를 비교했다.
- 6개 중5개는 고정 기준과 같은 출력이었다.
- V5 coherent-line 보호는 **PQ0.432256349 / FP2899 / FN3015**였다. 고정 기준보다FP20개 감소·FN3개 증가지만, 기존 P1의 **PQ0.433127851**보다 낮다.
- V5의 조건부95% ΔPQ 구간은 고정 기준 대비 **[+0.000059,+0.000726]**다. 이작은 양의 구간을 현재 최고를 넘었다는 근거로 쓰지 않는다.
- Baseline 특징은 exact RLE hash로만 연결했다. 이미 수정·병합된 마스크에 같은 index라는 이유로 원래 특징을 대입하지 않았다.

## 순위·군집 선택:4개와2개 전이

- Darkness 순위, ridge·방향 순위, 곡선 anisotropy 순위, family균형 군집 medoid를 비교했다.
- 같은Y1 후보 pool에서 순위만 바꾼 최선은 curve-rank의 **PQ0.430040791**로, 기존Y1 **0.430157068**보다도 낮았다.
- 고정 기준 대비 차이는−0.001833092, 조건부95% 구간은 **[−0.003311,−0.000351]**다.
- 최고 후보에 적용한 curve-rank와 cluster-medoid의 집계는 둘 다 **PQ0.434840297 / FP3046 / FN2914**였고, 현재 최고0.436752508보다 낮았다. 두 방법의 예측 자체는 동일하지 않으며 3개 사진의 마스크 집합이 달랐다.
- 짧은 metadata의 `max-confidence pivot` 표현은 실행소스를 정확히 요약하지 못했다. 실제 pivot 순서는 **지원 family 수 내림차순 → raw confidence 내림차순 → RLE 사전순**이고, 그 순서에서 IoU≥0.5의 미할당 후보를 묶었다. 이설명만 바로잡았으며 원본 소스·파라미터·예측·점수는 바꾸지 않았다.

## 다음 판단

- 원영상이 어둡고 선형이라는 사실만으로 정답의 객체 범위·분리와 IoU>0.5가 보장되지는 않는다. 이번 결과는 후보의 존재 신호와 마스크 품질 신호를 구분할 필요를 뒷받침한다.
- 따라서 현재 최고 후처리를 유지한다. 새 학습이 필요한 품질 추정은 사용자가 정한 **기존616/91 고정 분할에서 별도로 비교**해야 한다.
- 같은707장 OOF의 GT로 가중치를 학습하고 같은 자료의 점수 상승을 독립적인 검증으로 보고하지 않는다.
- 모든 bootstrap 구간은 반복 사용한 OOF와 선택한 후보에 조건부다. 선택 편향과 시간 상관을 보정한 최종 일반화 보장이 아니다.

근거는 `docs/evidence/pixel_quality_experiments_v4.json`에 설정20개의 규칙·점수·비교 기준·독립 CSV 재채점·출처 SHA와 함께 저장했다.
