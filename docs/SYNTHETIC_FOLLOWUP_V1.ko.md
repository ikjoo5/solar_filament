# 합성 학습 결과 이후의 후보 선택·U-Net 비교 실험

## 결론

저장된 예측으로 **45개 설정(기준선과 같은 출력을 내는 설정 포함)**을 실행했다. 이번 범위에서 큰 PQ 상승은 없었다. 현재 제출 기준선을 유지하고, 소폭 개선은 개발용 후보로만 보관한다.

사용자가 허용한 U-Net 전환도 비교했다. 현재 best84는 이미 ConvNeXt-tiny U-Net에 전경·전역 binary spine 출력을 둔 모델이다. 이 모델을 단독으로 사용하는 전환은 기존 YOLO+U-Net보다 낮았다. 이는 다른 U-Net 구조나 새 학습의 가능성을 부정하는 결과가 아니다.

## 평가 조건

- 같은 고정 validation 91장, 주석 그룹 101개, GT 708개를 사용했다.
- 기존 모델·합성 v2·합성 v3의 30에폭 결과와 고정 native의 저장 예측을 재사용했다. 추가 GPU 추론이나 모델 학습을 실행하지 않았다.
- 판단 규칙은 예측 마스크·confidence·모델 간 동의도로 계산했다. GT는 평가와 개발 규칙 선택에만 사용했다. 새 모델 가중치를 validation으로 학습하지 않았다.
- 기준선은 이번 실행에서 재현한 **PQ 0.4719300845 / FP 204 / FN 221**이다. 과거 PQ 0.472593과 구분한다.
- 이 세트는 오래 반복 사용한 개발 자료다. 아래 결과나 그룹별 선택 검사를 새 OOF·LB 성능으로 해석하지 않는다.

### 1. 보조 모델로 FN 복구 — 12개 설정

기존 마스크를 모두 보존하고 v3/v2의 공간적으로 새로운 후보만 추가했다. 기존 추론 뷰의 지지, U-Net 전경의 지지, confidence 기준을 함께 비교했다.

- 단순 추가는 새 GT 8개를 찾았지만 FP가 48개 늘어 PQ가 하락했다.
- confidence 0.30 이상 조건은 GT 4개 복구·FP 22개 증가로 PQ 0.467385였다.
- confidence 0.50 이상 조건은 GT 복구 없이 FP 3개만 늘었다. 0.70 이상은 아무것도 추가하지 않아 기준선과 같았다.
- v3를 직접 사용했을 때의 33개 복구 효과를 신규 영역 추가만으로 그대로 얻을 수 없었다. 중첩된 기존 후보의 선택·형상 변화도 함께 관련될 수 있다.
- 모든 설정에서 기존 마스크의 픽셀을 보존하고 최종 비중첩을 검사했다.

### 2. 모델 간 동의도로 FP 제거 — 12개 설정

가장 보수적인 관찰 개선은 다음 규칙이다.

1. 원본 최종 마스크와 IoU ≥0.30인 원본 raw 후보 중 최고 confidence를 계산한다.
2. 그 값이 0.40 이상이면 보존한다.
3. 그보다 낮고, 새 두 모델에서도 해당 마스크와 IoU ≥0.30인 raw 후보의 confidence가 모두 0.10 미만이면 제거한다.

이번 자료에서는 4장의 FP를 하나씩 제거해 **PQ +0.001353 / FP −4 / FN 변화 0**이었다. 해당 사진은 `20120227161654Bh`, `20120730135454Bh`, `20160726135354Bh`, `20210626060050Uh`다.

사진 단위 paired bootstrap 20,000회에서 이 고정 후보의 PQ 차이 구간은 [0.000313, 0.002827]이었다. 여러 규칙을 검색한 뒤 얻은 개발 결과이므로, 이 구간만으로 일반화 개선을 주장하지 않는다. 규칙을 실제 사용하려면 새 YOLO 두 모델의 추론이 추가된다. FP 4개 제거의 작은 관찰 효과에 비해 추론 비용이 늘어난다.

### 3. 중첩 후보 교체 — 10개 설정

서로 가장 가까운 기존·새 마스크를 연결하고, 면적비 0.5~1.5, IoU, 새 모델 간 동의도, confidence 차이로 교체를 제한했다. 인스턴스 수와 바꾸지 않은 기존 마스크의 픽셀을 보존했다.

최고 관찰 규칙은 v3의 confidence가 원본보다 0.05 이상 높고 서로 IoU ≥0.30인 경우다. 마스크 245개를 바꾸었지만 GT 5개 복구·4개 손실로 순이득은 1개였다. **PQ +0.000122**에 그쳤고 SQ는 0.677854→0.676640으로 낮아졌다. 큰 개선으로 채택할 근거가 없다.

### 4. 현재 U-Net 단독 — 11개 설정

저장된 5개 전경 임계값에 최소 면적 150/300을 비교하고, 과거 관찰 최고였던 0.5·면적 400도 포함했다.

- 기본 0.5·면적 300: PQ 0.430325, FP 315, FN 228.
- 이번 관찰 최고 0.8·면적 300: PQ 0.434251, FP 287, FN 240.
- 이전 45개 native 후처리 비교도 관찰 최고가 약 0.43144였으므로, 단순 U-Net 사용이 갑자기 새로운 강한 기준선이 된 것은 아니다.

현재 export에 있는 native 전경 임계값 0.2~0.8과 개별 뷰 0.5의 연결요소를 합치면 정답 후보가 있는 GT는 **522/708**, 작은 GT는 **116/180**이었다. YOLO의 객체 confidence 0.05 이상 4개 뷰에서는 각각 **635/708**, **150/180**이었다. 두 후보 합집합은 637/708이었다. 서로 다른 전경 임계값·객체 점수·디코딩을 비교한 것이므로 **현재 저장 자료의 후보 범위**로 해석하며 구조 자체의 성능 상한으로 해석하지 않는다.

기본 U-Net 출력에서 연결요소 17개가 서로 다른 GT 두 개 이상을 각각 50% 이상 덮었다. 이와 연관된 미검출 GT는 29개였다. 인스턴스 합침이 일부 FN과 연관되지만 모든 FN을 설명하지 않는다.

## 사진 묶음별 규칙 선택 검사

관측 월 55개를 월 문자열의 해시로 다섯 묶음에 배정했다. 같은 사진과 그 사진의 모든 주석자는 항상 같은 묶음에 둔다. 각 묶음을 제외한 나머지 자료에서 PQ가 높고 FN이 기준선보다 늘지 않는 규칙을 고른 뒤, 제외했던 묶음에 적용했다. 동점이면 기준선을 우선했다.

결과를 전체 GT 기준으로 합산하니 **PQ 0.468048 / FP 207 / FN 224**였다. 각 묶음의 PQ를 단순 평균한 값이 아니다. 전체에서 좋아 보였던 규칙을 선택해도 다른 묶음에 적용하면 효과가 유지되지 않는 경우가 있었다.

이는 모든 고정 규칙이 반드시 실패한다는 뜻은 아니다. 특히 FP 4개를 제거한 하나의 고정 규칙과, 여러 규칙 중 매번 선택하는 절차는 서로 다른 평가 대상이다. 다만 작은 개발 점수 차이를 근거로 제출 구성을 즉시 바꾸기 어렵다는 증거다.

이번 다섯 묶음은 **모델을 다시 학습한 5-fold가 아니다.** 반복 사용한 91장 개발 세트 안의 규칙 선택 진단이며, 인접 월 사이 시간적 embargo도 보장하지 않는다. 새로운 독립 검증으로 표현하지 않는다.

## 이후 모델 실험에 반영할 점

- YOLO 사용을 고정 조건으로 두지 않는다. 새 U-Net 구조도 같은 고정 train/validation에서 비교할 수 있다.
- 현재 U-Net의 단독 사용과 새로운 인스턴스 분리 학습은 구분한다. 새 구조를 실험한다면 기존 전경·spine에 더해 **인스턴스 경계 또는 같은 객체 여부를 예측하는 출력**을 검토한다.
- 후보 존재율과 최종 검출률을 별도 측정하고, GT 복구와 기존 GT 손실을 함께 기록한다. 인스턴스 분리만으로 전체 recall이 해결된다고 가정하지 않는다.
- 실제 데이터만 사용하는 동일 조건의 짧은 추가 학습 대조군으로 공통 optimizer·학습률·추가 학습 효과를 먼저 확인해야 한다. 이번 v2/v3 결과만으로 합성 데이터만 실패 원인이라고 결론 내리지 않는다.
- 새 v2/v3 모델은 원래 train 616장을 학습했다. 이 모델을 그대로 기존 707장 5-fold의 보조 모델로 넣어 평가하면, 여러 fold의 validation이 학습에 포함되는 누수가 생긴다. 707장 OOF로 검증하려면 보조 모델도 fold의 학습 범위를 지켜야 한다.
