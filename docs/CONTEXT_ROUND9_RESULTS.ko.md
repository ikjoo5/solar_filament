# 새 문맥 모델 업로드 검증과 결합 실험

이번 업로드는 100epoch 스케줄에서 **60epoch 완료 후 계획 중단**, 최고는 **45epoch**다.
첨부된 코드는 실행하지 않고 CSV·JSON·RLE만 읽었다. 검증 집합은 기존과 같은
물리 이미지 91개, annotator 그룹 101개, 정답 인스턴스 708개다.

같은 T4의 best84 예측 마스크는 ZIP에 없어 해당 기준 점수는 독립 재채점하지 못했다.
last60의 예측도 아직 없어 history 점수만 확인했다.

저장된 과거 best84 CSV와 비교한 물리 이미지 paired bootstrap PQ 차이의 조건부
95% 구간은 [-0.006086, +0.012294]다. 반복 선택한 개발셋이며 새 holdout이 아니므로
일반화 향상을 확정하지 않는다. 구조 변경과 추가 학습 효과도 분리할 수 없다.

RLE 5,223개, native 2048 좌표, 면적·범위·통계와 91장 이미지 SHA를 검증했다.
새 base threshold0.5·area300은 best CSV의 702개 물리 마스크와 정확히 같다.
중첩·중복·추가 all-pairs 매칭은 없다. 검증 파일과 합성 donor pool은 분리돼 있다.

## 기존 전체 파이프라인에 적용한 8개 고정 설정

YOLO 예측과 기존 후처리 수치는 고정하고 native 모델을 넣는 단계만 바꿨다.
모든 후보 CSV를 만든 뒤 정답을 읽었고, 저장 후 다시 채점했다.

최고 후보의 상승은 **+0.000362**다. 기존 GT 5개를 복구했지만 3개를 잃었고 FP도 4개
늘었다. 조건부 paired bootstrap 95% 차이 구간은 [-0.003854, +0.004703]이며
6개 관측소 중 2개만 PQ가 상승했다. **기존 제출 파이프라인은 변경하지 않았다.**

## FN 복구와 FP 증가를 함께 본 10개 고정 규칙

기존 625개 마스크를 byte 단위로 보존한 채 old/new native 모델의 서로 지지하는
누락 후보를 추가하는 6개 규칙을 실행했다. 엄격한 규칙은 추가 0개였다. 추가가 생긴
최고 후보는 TP494·FP226·FN214·PQ0.468882로, 정답 6개 복구보다 FP 증가 22개의
불이익이 컸다. 따라서 채택하지 않았다.

다음으로 YOLO라는 다른 구조의 추가 지지를 요구하는 4개 규칙을 실행했다.
confidence0.35/0.5, 한 family/두 family 지지와 IoU0.3을 고정했다. clipped tile은
제외했다. 결과 PQ는 0.470659, 0.471919, 0.471328, 0.472256으로 모두 기준보다
낮았다. 추가 gate를 정답에 맞춰 계속 잘게 튜닝하지 않았다.

총 18개 설정(기준 포함) 모두 실제 예측을 생성했고, 중첩·중복은 0개다.
새 체크포인트를 썼다는 이유만으로 기존 native 모델을 교체하지 않는다.

## 외부 MAGFiLO는 대회 데이터와 먼저 구분해야 한다

공식 Dataverse 공개 주석을 실제 내려받아 공식 MD5와 크기를 확인했다.
업로드한 전체 공식 파일명 목록으로 다시 대조한 결과, 958개 물리 이미지 중 대회
train/validation707개와 test180개가 모두 포함된다. 나머지71개는 외부 평가 후보다.
이전 미확정74개 중3개가 test였으며, 기존 제출 CSV만으로는 이3개를 확인할 수 없었다.

후보 원본71장(29.6MB)을 실제 확보하고2048픽셀·내부 중복0을 확인했다. 주석자별 레코드는
121개다. 공개 주석의 test 정답으로 후처리 설정을 선택하지 않았다. 남은 검사는 Drive의
대회원본887장과 파일·픽셀 중복 대조이며, 이를 위한 GPU 불필요 셀은
`notebooks/External71_Prepare_CopyCell.py`다. 외부 PQ는 아직 계산하지 않았다.

Shang2024 논문은 정답 train/test 자료를 저자에게 요청해야 한다고 명시한다.
Diercke2024의 공개 독립 정답 다운로드는 제한된 조사에서 확인하지 못했다.
원본 이미지 아카이브만 확보한 것을 정답이 있는 PQ 검증셋으로 세지 않는다.
