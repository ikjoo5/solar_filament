# CHASE 독립 검증과 후처리 진단

고정 GONG validation91장,101주석그룹,708객체에서 기존/CHASE60 가중치와 원본/limb 입력을 비교했다. YOLO와 native는 결합하지 않았으며 단일 base view와 최소 디코더를 사용했다. 아래는 public LB 및 기존 전체 복합모델 PQ와 구분해야 하는 개발 검증 수치다.

## 추가로 완료한 CPU 캐시 실험

- native FG 임계값0.05/0.1/0.2/0.35/0.5/0.65/0.8을 같은8연결요소·면적100 규칙으로 비교했다. CHASE 원본은0.5에서PQ0.072098,0.05에서0.084986이었다. 픽셀 recall은23.25%→26.01%였다.
- 사전에 지정한 반경3 팽창은 CHASE native 원본 PQ를0.120052로 올렸지만 FP도518→559로 늘었다. 같은 팽창은 기존 native 원본 PQ를0.400068→0.242995로 낮췄다. 작은 마스크 범위가 하나의 문제라는 단서이지, 이 규칙을 운영에 채택했다는 의미는 아니다.
- YOLO confidence0.05/0.1/0.2/0.35/0.5/0.7 비교에서 CHASE 원본의 관측 최고는0.089523,limb는0.101528이었다. 반복 사용한 개발셋에서 고른 값이며 독립 검증 점수가 아니다.
- 단일 base view의 저장된 후보 중 IoU>0.5 후보가 있는 GT는 기존 YOLO 원본585/708,CHASE 원본99/708이었다. 저장 전 conf0.05/NMS0.7의 영향은 포함돼 있다. 전체30뷰 파이프라인의 후보 재현율로 일반화하지 않는다.
- CHASE YOLO 원본 FP579개 중317개는 예측 픽셀90% 이상이 한 GT 안에 있지만 그 GT의 절반 이하만 덮었다. 위치가 맞는 작은 조각도 instance IoU 기준에서 FP/FN을 동시에 만들 수 있다.

## 해석과 다음 방향

단순 limb 제거·임계값 변경·작은 팽창은 기존 성능을 회복하지 못했다. CHASE 자체가 쓸모없다는 결론이 아니라 CHASE-only60epoch 적응 방식의 재설계가 필요하다는 결과다. 영상 분포, 자동 라벨의 범위·객체 단위, 원래 GONG 표현을 잃는 영향은 아직 각각의 인과 기여를 분리하지 못했다.

현재 보유 구현과 자료 기준으로 CHASE 양성 마스크 형태를 GONG train 배경·명암에 넣는 국소 합성을 먼저 비교하는 방향을 권한다. 실제 CHASE 혼합과 관측 특성 변환도 후속 대조군으로 유지한다. [선택 이유·미구현 부분·동일 예산 실험 설계](CHASE_GONG_NEXT_EXPERIMENT.ko.md)를 참고한다. SWEFFI는 마지막 단계로 보류한다.

원시 예측·정답·분할·이미지·체크포인트는 저장소에 포함하지 않는다. 재현 코드는 `tools/chase_independent_plain_worker.py`, `tools/chase_independent_decode.py`, `tools/chase_postprocess_ablation.py`에 있다. 이 문서는 실제 완료된 실험을 기록하며 신규 학습이나 신규 변환의 성능 향상을 주장하지 않는다.
